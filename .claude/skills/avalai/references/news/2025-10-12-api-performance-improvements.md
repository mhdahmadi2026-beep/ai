# بهبودهای عملکرد API

**تاریخ:** ۱۴۰۴-۰۷-۲۰ / (2025-10-12)

## خلاصه

پس از سه ماه بهینه‌سازی جامع زیرساخت، AvalAI اکنون تاخیر کمتری نسبت به دسترسی مستقیم به OpenAI برای مدل gpt-4o-mini ارائه می‌دهد. آخرین بنچمارک‌های ما نشان می‌دهند که زمان پاسخ ۳۹ تا ۴۴٪ سریع‌تر و توان عملیاتی توکن ۷۷٪ بالاتر در مناطق مختلف است که از طریق اتصالات پایدار به ارائه‌دهندگان، بهینه‌سازی مدیریت اتصال و بهبودهای هدفمند زیرساخت به‌دست آمده است.


## مشاهده بنچمارک‌های کامل

برای داده‌های عملکردی جامع، روش‌شناسی و توانایی بازتولید این نتایج، از [صفحه عملکرد](fa/performance.md) ما بازدید کنید.
