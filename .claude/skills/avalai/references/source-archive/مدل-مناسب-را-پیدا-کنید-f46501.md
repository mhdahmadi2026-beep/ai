# مدل مناسب را پیدا کنید

همه مدل‌های شناخته‌شده را جستجو کنید، قابلیت‌ها و شواهد بنچمارک را مقایسه کنید و راهنمای عملی API در AvalAI را باز کنید.

<ModelExplorer />

## مرور ارائه‌دهندگان مدل

از فیلتر ارائه‌دهنده استفاده کنید یا [مستندات ارائه‌دهنده OpenAI](/fa/providers/openai) را ببینید.

## انتخاب مدل

- ابتدا دسترسی، نوع ورودی و خروجی و سازگاری endpoint را بررسی کنید.
- قیمت AvalAI و پنجره زمینه را متناسب با بار کاری مقایسه کنید.
- بنچمارک خارجی را شواهد مقایسه بدانید، نه یک امتیاز جهانی.
