# API جستجوی وب: 8 ابزار جستجو از ارائه‌دهندگان پیشرو

**تاریخ:** 1404-08-4 / (2025-10-26)

## خلاصه

AvalAI اکنون از قابلیت جستجوی وب از طریق اندپوینت v1/search پشتیبانی می‌کند و 8 ابزار جستجوی تخصصی از 6 ارائه‌دهنده پیشرو را ارائه می‌دهد. این ابزارها امکان جستجوی وب در زمان واقعی با فیلترهای قابل تنظیم، محدودیت‌های دامنه و نتایج خاص هر کشور را فراهم می‌کنند، همگی از طریق یک API یکپارچه سازگار با Perplexity قابل دسترسی هستند.

---

## جزئیات

ما قابلیت‌های جستجوی جامع را به AvalAI معرفی می‌کنیم و به توسعه‌دهندگان دسترسی به موتورهای جستجوی متعدد از طریق یک اندپوینت API یکپارچه را فراهم می‌کنیم. اندپوینت جدید [`v1/search`](fa/api-reference/search.md) از 8 ابزار جستجوی مختلف از 6 ارائه‌دهنده اصلی پشتیبانی می‌کند و به شما امکان می‌دهد بهترین موتور جستجو را برای مورد استفاده خاص خود انتخاب کنید.

### ابزارهای جستجوی پشتیبانی شده

#### Perplexity
- **perplexity-search**: جستجوی سریع با هوش مصنوعی و نتایج با کیفیت. [مستندات](fa/providers/perplexity.md)

#### Tavily
- **tavily-search**: جستجوی استاندارد با پوشش جامع وب. [مستندات](fa/providers/tavily.md)
- **tavily-search-advanced**: جستجوی پیشرفته با فیلترینگ پیشرفته و نتایج عمیق‌تر. [مستندات](fa/providers/tavily.md)

#### DataForSEO
- **dataforseo-search**: موتور جستجوی مقرون به صرفه با نتایج قابل اعتماد. [مستندات](fa/providers/dataforseo.md)

#### Exa AI
- **exa_ai-search**: موتور جستجوی عصبی بهینه شده برای کوئری‌های معنایی. [مستندات](fa/providers/exa_ai.md)

#### Google PSE
- **google_pse-search**: موتور جستجوی قابل برنامه‌ریزی گوگل برای تجربه‌های جستجوی سفارشی. [مستندات](fa/providers/google.md)

#### Parallel AI
- **parallel_ai-search**: پردازش جستجوی موازی سریع. [مستندات](fa/providers/parallel_ai.md)
- **parallel_ai-search-pro**: نسخه پیشرفته با ویژگی‌های اضافی و نتایج با کیفیت بالاتر. [مستندات](fa/providers/parallel_ai.md)

### ویژگی‌های کلیدی

- **API یکپارچه**: سازگار با فرمت API جستجوی Perplexity
- **گزینه‌های کوئری انعطاف‌پذیر**: پشتیبانی از کوئری‌های جستجوی تکی یا چندگانه
- **فیلتر دامنه**: محدود کردن نتایج به دامنه‌های خاص (تا 20 دامنه)
- **فیلتر کشور**: دریافت نتایج جستجوی خاص منطقه
- **کنترل نتایج**: سفارشی‌سازی تعداد نتایج (1-20) و توکن‌ها در هر صفحه
- **گزینه‌های مقرون به صرفه**: انتخاب از بین ارائه‌دهندگان متعدد بر اساس بودجه و نیازهای شما

## نمونه درخواست/پاسخ API

### نمونه درخواست (گزینه 1: ابزار جستجو در URL)

```bash
curl https://api.avalai.ir/v1/search/perplexity-search \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "latest AI developments 2024",
    "max_results": 5,
    "search_domain_filter": ["arxiv.org", "nature.com"],
    "country": "US"
  }'
```

### نمونه درخواست (گزینه 2: ابزار جستجو در بدنه)

```bash
curl https://api.avalai.ir/v1/search \
  -H "Authorization: Bearer $AVALAI_API_KEY" \

  -d '{
    "search_tool_name": "perplexity-search",
    "query": "latest AI developments 2024",
    "max_results": 5
  }'
```

## نمونه استفاده از SDK

### جستجوی پایه

```language-selector
bash=:curl https://api.avalai.ir/v1/search/tavily-search \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "artificial intelligence trends",
    "max_results": 10
  }'

python=:import requests

response = requests.post(
    "https://api.avalai.ir/v1/search/tavily-search",
    headers={"Authorization": f"Bearer {api_key}", "Content-Type": "application/json"},
    json={"query": "artificial intelligence trends", "max_results": 10},
)

results = response.json()
for result in results["results"]:
    print(f"{result['title']}: {result['url']}")

javascript=:const response = await fetch("https://api.avalai.ir/v1/search/tavily-search", {
    method: "POST",
    headers: {
        "Authorization": `Bearer ${process.env.AVALAI_API_KEY}`,
        "Content-Type": "application/json"
    },
    body: JSON.stringify({
        query: "artificial intelligence trends",
        max_results: 10
    })
});

const data = await response.json();
data.results.forEach(result => {
    console.log(`${result.title}: ${result.url}`);
});

```
