# بسته‌های اعتباری AvalAI

> **📞 پشتیبانی و بازخورد**
>
> برای دریافت کمک یا گزارش مشکلات مربوط به این مستندات، با تیم پشتیبانی ما در تلگرام تماس بگیرید: [t.me/AvalAISupport](https://t.me/AvalAISupport)
>
> ما آماده پاسخگویی به سوالات فنی، استعلامات مالی و بهبود مستندات هستیم.

بسته‌های اعتباری AvalAI اعتبار پیش‌پرداخت API برای مدل‌های OpenAI، Gemini، Alibaba و مدل‌های برتر کدنویسی هستند. در این فهرست زنده می‌توانید قیمت خرید، مبلغ اعتبار دریافتی، درصد تخفیف، مدت اعتبار، سقف خرید، وضعیت موجودی و شناسه دقیق مدل‌های تحت پوشش را مقایسه کنید تا بسته مناسب مصرف و بودجه خود را انتخاب کنید.

## 📋 راهنمای انتخاب مناسب

> **💡 برای کاربران جدید**
>
> اگر تازه با AvalAI شروع می‌کنید، **نیازی به خرید بسته اعتباری نیست**. بهترین راه شروع، شارژ موجودی اعتباری پیش‌فرض حساب شما و استفاده مستقیم از سرویس‌هاست. این روش انعطاف کامل در انتخاب مدل‌ها و عدم محدودیت زمانی را فراهم می‌کند.

> **🏢 برای کاربران حرفه‌ای و سازمانی**
>
> بسته‌های اعتباری برای کاربران حرفه‌ای و سازمانی طراحی شده‌اند که:
> - الگوی استفاده مشخص و قابل پیش‌بینی دارند
> - از مدل‌های خاصی به طور مکرر استفاده می‌کنند
> - می‌خواهند از تخفیف‌های قابل توجه بهره‌مند شوند
> - قادر به استفاده از اعتبارات در بازه زمانی محدود هستند
>
> **توجه**: بسته‌های اعتباری دارای محدودیت زمانی (در حال حاضر ۱ تا ۳۱ روز) و محدوده سرویس مشخص هستند.

> **⚠️ هشدار مهم - الزامات موجودی حساب**
>
> جهت بهره‌مندی موثر از بسته‌های اعتباری، ضروری است که موجودی کلی حساب شما (اعتبار پیش‌فرض) مثبت باشد. **در صورت صفر یا منفی شدن موجودی کلی، سرویس‌های API به طور خودکار غیرفعال خواهند شد**.
>
> **توصیه مهم**: حداقل مبلغ **۱۰۰,۰۰۰ تومان** در موجودی کلی حساب خود حفظ نمایید تا ارائه سرویس بدون وقفه ادامه یابد و بسته‌های اعتباری به درستی عمل کنند.

> **⚠️ محدودیت سطح سرویس Flex**
>
> بسته‌های اعتباری هزینه‌های [سطح سرویس Flex](fa/pricing.md#سطح-سرویس-flex) را پوشش **نمی‌دهند**. هنگام استفاده از `service_tier: "flex"` در درخواست‌های API، هزینه‌ها از موجودی استاندارد حساب شما کسر می‌شود، نه از تخصیص بسته‌های اعتباری.
>
> بسته‌های اعتباری فقط برای استفاده از سطح سرویس استاندارد (`service_tier: "default"` یا بدون مشخص کردن سطح سرویس) اعمال می‌شوند.

## بسته‌های اعتباری چیست؟

بسته‌های اعتباری، محصولات مالی ویژه‌ای هستند که به شما اعتباری بیشتر از مبلغ پرداختی‌تان می‌دهند، البته با محدودیت‌هایی در مورد مدل‌هایی که می‌توانید استفاده کنید. برای مثال، شما ممکن است ۳۵۰,۰۰۰ تومان پرداخت کنید، اما ۵۰۰,۰۰۰ تومان اعتبار (معادل ۲۵٪ اعتبار بیشتر) دریافت کنید که تنها برای استفاده با مدل‌های خاص هوش مصنوعی و در یک بازه زمانی محدود قابل استفاده است.

### مزایای اصلی

- **صرفه‌جویی در هزینه**: بسته‌های موجود فعلی، ارزش اعتبار درج‌شده را با ۲۰٪ تا ۴۰٪ تخفیف ارائه می‌کنند.
- **دسترسی به مدل‌های برتر**: با نرخ‌های تخفیف‌دار به مدل‌های پیشرفته دسترسی پیدا کنید.
- **گزینه‌های منعطف**: بسته‌های متنوعی متناسب با نیازها و بودجه‌های مختلف در دسترس هستند.
- **شفافیت در قیمت‌گذاری**: نسبت‌های ارزش و محدودیت‌های مدل به وضوح مشخص شده‌اند.

## نحوه عملکرد بسته‌های اعتباری

### ساختار بسته

هر بسته اعتباری شامل موارد زیر است:

- **مبلغ پرداختی**: هزینه‌ای که شما می‌پردازید (مثلا ۳۵۰,۰۰۰ تومان).
- **ارزش اعتبار**: کل اعتباراتی که دریافت می‌کنید (مثلا ۵۰۰,۰۰۰ تومان).
- **نسبت ارزش**: درصد اعتبار اضافی که دریافت می‌کنید (مثلا ۲۵٪ اعتبار بیشتر).
- **محدوده بسته**: مدل‌ها یا سرویس‌های خاصی که بسته پوشش می‌دهد.
- **دوره اعتبار**: مدت زمانی که بسته فعال باقی می‌ماند.
- **محدودیت‌های استفاده**: حداکثر تعداد خرید برای هر کاربر.

### محدوده‌های بسته

بسته‌های اعتباری به محدوده‌ها و مدل‌های خاصی محدود می‌شوند:

- **تمرکز بر سرویس API**: تمامی بسته‌های فعلی بر استفاده از API متمرکز هستند و شامل سرویس‌های اشتراکی نمی‌شوند.

### اعتبار و انقضا

- بسته‌های فعلی دارای دوره‌های اعتبار ثابت ۱، ۷، ۳۰ یا ۳۱ روز هستند.
- اعتبارات به طور خودکار پس از پایان دوره اعتبار منقضی می‌شوند.
- **لغو مشروط**: بسته پرداخت‌شده جدید با مصرف اندک ممکن است طبق سیاست بازگشت به کیف پول زیر واجد شرایط باشد؛ بسته منقضی‌شده یا بسته‌ای که شرایط را ندارد، قابل لغو نیست.
- **غیرقابل انتقال**: اعتبارات نمی‌توانند بین حساب‌ها یا بسته‌ها منتقل شوند.

- **احراز هویت الزامی**: برای خرید بسته باید وارد حساب کاربری خود شده باشید.
- **روش‌های پرداخت**: امکان پرداخت با کارت بانکی یا از طریق موجودی اعتباری موجود در حساب شما.
- **تایید**: برای تکمیل خرید، تایید یک‌بار مصرف (OTP) مورد نیاز است.

### فرآیند خرید

1. **مرور بسته‌ها**: به [بخش بسته‌های صورتحساب AvalAI](https://chat.avalai.ir/platform/billing/packages?marketplace) مراجعه کنید.
2. **انتخاب بسته**: بسته و تعداد مورد نظر خود را انتخاب کنید.
3. **روش پرداخت**: کارت بانکی یا موجودی اعتباری را به عنوان روش پرداخت انتخاب کنید.
4. **تایید OTP**: کد ۶ رقمی ارسال‌شده به تلفن همراه خود را وارد کنید.
5. **تایید نهایی**: بسته بلافاصله به حساب شما اضافه می‌شود.

## مدیریت بسته‌های اعتباری شما

### داشبورد بسته

از طریق [پلتفرم AvalAI](https://chat.avalai.ir/platform/billing/packages?marketplace) به داشبورد بسته‌های خود دسترسی پیدا کنید تا:

- بسته‌های فعال و منقضی‌شده را مشاهده کنید.
- آمار دقیق استفاده را نظارت کنید.
- جدول زمانی انقضای بسته‌ها را بررسی کنید.
- اعتبارات باقی‌مانده خود را پیگیری کنید.

### انواع وضعیت بسته

- **فعال**: بسته معتبر است و اعتبارات باقی‌مانده دارد.
- **منقضی‌شده**: دوره اعتبار بسته به پایان رسیده است.
- **تمام‌شده**: تمامی اعتبارات بسته استفاده شده است.
- **تبلیغاتی**: بسته‌هایی با تخفیف‌ها و پیشنهادهای ویژه.

### پیگیری استفاده

میزان استفاده از بسته خود را از طریق بخش‌های زیر نظارت کنید:

- **موجودی لحظه‌ای**: نمایش اعتبارات باقی‌مانده فعلی.
- **تجزیه و تحلیل استفاده**: الگوهای مصرف دقیق شما.
- **تفکیک مدل**: مشاهده میزان اعتبارات استفاده‌شده برای هر مدل.
- **هشدارهای انقضا**: دریافت اعلان‌ها قبل از انقضای بسته‌ها.

## شرایط و ضوابط مهم

### الزامات موجودی حساب

- **موجودی مثبت ضروری**: موجودی کلی حساب شما باید همیشه مثبت باشد تا بسته‌های اعتباری به درستی عمل کنند.
- **قطع خودکار سرویس**: در صورت صفر یا منفی شدن موجودی کلی، تمامی سرویس‌های API به طور فوری غیرفعال می‌شوند.
- **حداقل موجودی توصیه‌شده**: حفظ حداقل ۱۰۰,۰۰۰ تومان در موجودی کلی برای اطمینان از عملکرد بدون وقفه.
- **اولویت استفاده**: اعتبارات بسته قبل از موجودی کلی مصرف می‌شوند، اما موجودی کلی همچنان باید مثبت باقی بماند.

### سیاست لغو مشروط و بازگشت اعتبار به کیف پول

لغو بسته فقط زمانی ممکن است که هنگام تأیید نهایی همه شرایط زیر برقرار باشند:

- درخواست باید به‌طور دقیق پیش از `purchased_at + 24 hours` ثبت شود.
- اعتبار مصرف‌شده بسته حداکثر **۵٫۰۰٪** از اعتبار اسمی بسته باشد؛ مقدار دقیق ۵٫۰۰٪ نیز مجاز است.
- بسته فعال باشد، قبلاً لغو نشده باشد و به یک `Payment` تأییدشده با `paid_amount` مثبت و `allocated_paid_amount` مثبت متصل باشد.
- مبلغ بازگشت به کیف پول مثبت باشد. بسته‌های دستی یا تبلیغاتی که تخصیص Payment ندارند، واجد شرایط نیستند.

پیش‌نمایش و تأیید قفل‌شده هر دو از فرمول‌های زیر استفاده می‌کنند:

- `consumed_irt = amount_irt - remaining_irt`
- `wallet_return = allocated_paid_amount - consumed_irt`

لغو به کد یک‌بارمصرف نیاز دارد که ابتدا از طریق پیامک ارسال می‌شود. فقط اگر پیامک در دسترس نباشد، ایمیل تأییدشده استفاده می‌شود. هنگام تأیید، شرایط و مصرف با قفل‌کردن بسته، تخصیص پرداخت، پرداخت، کیف پول و وضعیت مصرف مرتبط دوباره بررسی می‌شوند. لغو موفق بسته را غیرفعال می‌کند، اعتبار باقی‌مانده آن را حذف می‌کند و فقط `wallet_return` را به `Credit.remaining_irt` می‌افزاید. این عملیات فقط اصلاح اعتبار حساب است و هرگز بازپرداخت بانکی نیست.

- **عدم تمدید**: بسته‌های منقضی‌شده نمی‌توانند تمدید شوند.
- **عدم انتقال**: اعتبارات نمی‌توانند بین حساب‌ها یا بسته‌ها منتقل شوند.

### قوانین انقضا

- **اعتبار ثابت**: هر بسته دارای یک دوره اعتبار از پیش تعیین‌شده است.
- **انقضای خودکار**: اعتبارات هنگام پایان دوره اعتبار بسته به طور خودکار حذف می‌شوند.
- **عدم مهلت اضافی**: پس از انقضا، هیچ زمان اضافی برای استفاده از اعتبارات فراهم نمی‌شود.
- **اثر فوری**: انقضا دقیقا در لحظه پایان دوره اعتبار رخ می‌دهد.

### محدودیت‌های استفاده و سقف خرید

- **محدودیت محدوده**: اعتبار هر بسته فقط برای مدل‌های مجاز همان بسته قابل استفاده است.
- **محاسبه با نرخ استاندارد**: استفاده از مدل‌های خارج از پوشش بسته با نرخ عادی محاسبه می‌شود.
- **یک بسته فعال از هر نوع**: وقتی روی کارت بسته عبارت **سقف ۱ خرید برای هر کاربر** درج شده است، نمی‌توانید هم‌زمان بیش از یک بسته فعال با همان شناسه قالب داشته باشید. برای مثال، تا زمانی که یک بسته `d-g3050s` فعال است، خرید بسته دیگری با شناسه `d-g3050s` امکان‌پذیر نیست.
- **عدم امکان رزرو بسته**: بسته اعتباری را نمی‌توان از قبل خرید و به‌صورت در انتظار یا رزروشده نگهداری کرد تا پس از پایان بسته فعال شود. بسته جدید از همان نوع فقط زمانی قابل خرید است که بسته فعلی دیگر فعال نباشد.
- **امکان خرید بسته‌های متفاوت**: می‌توانید هم‌زمان چند بسته اعتباری فعال داشته باشید، به شرطی که نوع آن‌ها متفاوت باشد و شناسه قالب یکسان نداشته باشند؛ سقف درج‌شده روی کارت هر بسته همچنان اعمال می‌شود.
- **سقف‌های ویژه**: اگر روی کارت **سقف ۲ خرید برای هر کاربر** درج شده باشد، حداکثر دو بسته فعال از همان نوع مجاز است. سایر سقف‌ها دقیقا مطابق کارت اعمال می‌شوند.
- **اتصال به حساب**: بسته‌ها به حساب کاربری خریدار متصل هستند.

### پوشش مدل

محدوده بسته تعیین می‌کند که کدام مدل‌ها نرخ‌های تخفیف‌دار را دریافت می‌کنند:

- **استفاده در محدوده**: نرخ‌های تخفیف‌دار به طور خودکار اعمال می‌شوند.
- **استفاده خارج از محدوده**: قیمت‌گذاری استاندارد اعمال می‌شود.
- **استفاده ترکیبی**: اعتبارات بر اساس پوشش مدل مصرف می‌شوند.
- **ترتیب اولویت**: اعتبارات بسته قبل از موجودی عمومی حساب شما استفاده می‌شوند.

## بهترین شیوه‌ها

### انتخاب بسته مناسب

1. **تحلیل الگوهای استفاده**: میزان و نوع استفاده معمول خود از مدل‌ها را بررسی کنید.
2. **محاسبه ارزش**: صرفه‌جویی حاصل از بسته را با نرخ‌های استاندارد مقایسه کنید.
3. **بررسی مدت اعتبار**: اطمینان حاصل کنید که می‌توانید اعتبارات را در بازه زمانی مشخص‌شده استفاده کنید.
4. **نیازهای مدل**: تایید کنید که بسته انتخابی، مدل‌های مورد نیاز شما را پوشش می‌دهد.

### بیشینه‌سازی ارزش

- **برنامه‌ریزی استفاده**: ابتدا اعتبارات بسته را برای مدل‌های پرکاربرد یا با ارزش بالا استفاده کنید.
- **نظارت بر انقضا**: دوره‌های اعتبار را به دقت پیگیری کنید.
- **پردازش دسته‌ای**: کارهای فشرده را در طول دوره اعتبار بسته انجام دهید.
- **انتخاب مدل هوشمندانه**: برای حداکثر صرفه‌جویی، مدل‌های تحت پوشش بسته را در اولویت قرار دهید.

## عیب‌یابی

### مسائل رایج

**بسته ظاهر نمی‌شود**
- تکمیل پرداخت و تایید OTP را مجددا بررسی کنید.
- وضعیت احراز هویت حساب خود را چک کنید.
- اگر پرداخت پردازش شده اما بسته موجود نیست، با پشتیبانی تماس بگیرید.

**اعتبارات اعمال نمی‌شوند**
- اطمینان حاصل کنید که از مدل‌های داخل محدوده بسته استفاده می‌کنید.
- تایید کنید که بسته هنوز در دوره اعتبار خود قرار دارد.
- بررسی کنید که آیا اعتبارات بسته تمام شده است.

**مشکلات پرداخت**
- برای پرداخت با موجودی اعتباری، از کافی بودن موجودی خود اطمینان حاصل کنید.
- برای پرداخت با کارت بانکی، از موجودی کافی کارت خود مطمئن شوید.
- فرآیند تایید OTP را به درستی تکمیل کنید.

**قطع ناگهانی سرویس**
- اگر سرویس‌های API شما قطع شده‌اند، ابتدا موجودی کلی حساب خود را بررسی کنید.
- اطمینان حاصل کنید که موجودی کلی مثبت است (حداقل ۱۰۰,۰۰۰ تومان توصیه می‌شود).
- پس از شارژ موجودی کلی، سرویس‌ها به طور خودکار فعال خواهند شد.

### تایید استفاده از بسته اعتباری

اگر نیاز دارید تایید کنید که آیا یک درخواست API خاص از اعتبارات بسته شما استفاده کرده است، می‌توانید از API جستجوی تراکنش یا گزارش‌های داشبورد استفاده کنید.

#### استفاده از API جستجوی تراکنش

از هدر `avalai-request-id` در هر پاسخ API برای جستجوی اطلاعات دقیق تراکنش استفاده کنید:

```bash
curl https://api.avalai.ir/user/v1/transactions/lookup \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -d '{
    "transaction_ids": ["شناسه-درخواست-شما"]
  }'
```

پاسخ دقیقا نشان می‌دهد که تراکنش چگونه محاسبه شده است:

```json
{
  "transactions": [
    {
      "id": "019b4a90-bfed-7cc1-97c1-7abcc10e7e75",
      "model": "qwen3-max",
      "cost": {
        "unit": "0.00007800",
        "paid_unit": "0.00007800",
        "paid_irt": "0",
        "paid_grant_irt": "10.35",
        "source": "credit_package",
        "currency": "UNIT"
      },
      "packages": [
        {
          "id": "7794",
          "template_id": "d-a3550s",
          "name": "منتخب Alibaba روزانه پایه",
          "remaining_irt": "499507.15",
          "end_date": "2025-12-24T09:24:02.705Z"
        }
      ]
    }
  ]
}
```

**فیلدهای کلیدی برای بررسی:**

| فیلد | توضیح |
|-------|-------------|
| `cost.source` | نمایش `"credit_package"` اگر بسته استفاده شده، `"balance"` اگر از موجودی کلی کسر شده |
| `cost.paid_irt` | مبلغ کسر شده از موجودی کلی (۰ اگر بسته اعتباری هزینه را پوشش داده) |
| `cost.paid_grant_irt` | مبلغ کسر شده از بسته اعتباری |
| `packages` | جزئیات بسته اعتباری فعال استفاده شده |
| `packages[].remaining_irt` | موجودی باقی‌مانده در بسته اعتباری |
| `packages[].end_date` | زمان انقضای بسته اعتباری |

برای جزئیات بیشتر در مورد API جستجوی تراکنش، به [مرجع API کاربر](fa/api-reference/user.md) مراجعه کنید.

#### استفاده از گزارش‌های داشبورد

همچنین می‌توانید گزارش‌های جامع استفاده را از طریق داشبورد AvalAI تولید کنید:

1. به [گزارش‌های استفاده](https://chat.avalai.ir/platform/usage/reports) مراجعه کنید
2. بازه زمانی مورد نظر خود را انتخاب کنید
3. یک **گزارش CSV** شامل تمام جزئیات تراکنش تولید کنید
4. گزارش شامل ستون‌هایی برای منبع هزینه، اطلاعات بسته و جزئیات صورتحساب است

این برای موارد زیر مفید است:
- حسابرسی استفاده از بسته اعتباری در طول زمان
- تطبیق صورتحساب ماهیانه
- صادرات داده‌ها برای اهداف حسابداری
- تحلیل الگوهای استفاده در مدل‌های مختلف
