در دوران رو به رشد هوش مصنوعی، داده‌های خصوصی کاربران به شکلی فزاینده در معرض تهدید قرار گرفته‌اند. اگرچه بهره‌گیری از خدمات پیشرفته هوش مصنوعی غالبا مستلزم تعامل با سرویس‌های خارجی است، اما ما به ضرورت حیاتی کاهش حداکثری خطر نقض حریم خصوصی و پیشگیری از پیامدهای فاجعه‌بار ناشی از رویدادهای غیرمترقبه (مانند نفوذ به سیستم، حملات سایبری و هک‌های احتمالی) واقفیم. از این رو، ما سیاست عدم نگهداری محتوای فراخوانی‌های API را در پیش گرفته‌ایم تا ریسک نشت احتمالی داده‌های کاربران را، حتی در بدترین سناریوها نظیر دسترسی غیرمجاز یا نقض‌های امنیتی، به طور کامل از میان برداریم.

## عدم جمع‌آوری، ذخیره‌سازی یا استفاده از محتوای فراخوانی‌های API

**AvalAI سیاست عدم نگهداری محتوای فراخوانی‌های API شما را به طور قاطع اجرا می‌کند.** این به آن معناست که ما **هیچ‌گونه داده خصوصی کاربران را از بدنه درخواست‌های API شما جمع‌آوری، ذخیره یا مورد استفاده قرار نمی‌دهیم.** این شامل، اما محدود به موارد زیر نیست:

*   **پرامپت‌ها (Prompts):** ورودی‌های متنی ارائه شده به مدل‌های ما.
*   **پیام‌ها (Messages):** مکالمات در تکمیل‌های چت.
*   **داده‌های صوتی (Audio Data):** ورودی‌های صوتی برای خدمات رونویسی یا تبدیل گفتار به متن.
*   **داده‌های تصویری (Image Data):** ورودی‌های بصری برای تحلیل یا تولید تصویر.
*   **هر محتوای دیگری** که بدنه فراخوانی API شما را تشکیل می‌دهد.

داده‌های حساس شما کاملا خصوصی باقی می‌مانند و بدون هیچ‌گونه ثبت یا ذخیره‌سازی در سیستم‌های ما، صرفا برای تولید پاسخ فوری و به صورت بلادرنگ پردازش می‌شوند.

## داده‌های مورد استفاده برای صورت‌حساب و ایمنی

به منظور تضمین محاسبات قیمت‌گذاری منصفانه و حفظ ایمنی و امنیت خدمات API ما، ما **تنها حداقل و غیرخصوصی‌ترین اطلاعات مربوط به تاریخچه فراخوانی‌های API را نگهداری می‌کنیم.** این داده‌های محدود شامل موارد زیر است:

*   **نام مدل (Model Name):** مدل هوش مصنوعی خاصی که برای یک درخواست استفاده شده است.
*   **آدرس IP:** برای اهداف امنیتی و جلوگیری از سو استفاده.
*   **مهر زمانی (Timestamp):** زمان وقوع فراخوانی API.
*   **معیارهای استفاده (Usage Metrics):** مانند تعداد توکن‌ها برای اهداف صورت‌حساب.

این اطلاعات صرفا برای الزامات عملیاتی مانند صورت‌حساب، مدیریت محدودیت‌های نرخ (rate limiting) و شناسایی موارد احتمالی سو استفاده به کار گرفته می‌شود و **تحت هیچ شرایطی برای تعامل، تحلیل یا بهره‌برداری از محتوای خصوصی شما استفاده نمی‌گردد.**

## سلب مسئولیت در قبال ارائه‌دهندگان شخص ثالث

درک این نکته ضروری است که AvalAI به عنوان یک دروازه عمل می‌کند و فراخوانی‌های API شما را به ارائه‌دهندگان اصلی مدل‌های هوش مصنوعی هدایت می‌کند. **AvalAI صرفا مسئولیت خدمات خود را بر عهده دارد و هیچ کنترلی بر روی رویه‌های حریم خصوصی یا سیاست‌های مدیریت داده این ارائه‌دهندگان شخص ثالث ندارد.**

به کاربران قویا توصیه می‌شود که سیاست‌های حریم خصوصی و شرایط خدمات ارائه‌دهندگان اصلی را برای هر مدلی که انتخاب می‌کنند، به دقت بررسی کنند. به عنوان مثال:

* اگر از مدل `gpt-5.4` استفاده می‌کنید، فراخوانی API شما به **OpenAI** صورت می‌گیرد.
* اگر از مدل `gemini-2.5-pro` استفاده می‌کنید، فراخوانی API شما به **Google Gemini AI Studio** صورت می‌گیرد.
* و همین‌طور برای سایر مدل‌ها و ارائه‌دهندگان مربوطه آن‌ها.

درک شما از سیاست‌های آن‌ها برای تضمین حریم خصوصی داده‌هایتان حیاتی است.

## تعهد به حریم خصوصی کاربر
 
تعهد ما به حریم خصوصی کاربران، تمامی خدمات AvalAI را در بر می‌گیرد. در پلتفرم چت ما، کنترل دقیق بر استفاده از داده‌ها از طریق تنظیماتی مانند «کمک به بهبود مدل» (که به صورت پیش‌فرض غیرفعال است) ارائه می‌شود. با این حال، در مورد خدمات API ما، اقدامات حریم خصوصی ما حتی سختگیرانه‌تر است و **هیچ‌گونه تعاملی با محتوای فراخوانی‌های API شما صورت نمی‌گیرد.**
 
ما بر این باوریم که باید کاربران خود را با ابزارهای قدرتمند هوش مصنوعی توانمند سازیم، در حالی که بالاترین استانداردهای حفاظت از داده‌ها را نیز رعایت کنیم. اعتماد شما برای ما از اهمیت ویژه‌ای برخوردار است و سیاست محتوای API ما بازتاب‌دهنده این ارزش بنیادین است.
