# مدل‌های Black Forest Labs (BFL)

AvalAI دسترسی یکپارچه به مدل‌های FLUX شرکت Black Forest Labs را از طریق API واحد خود فراهم می‌کند. این صفحه جزئیات مدل‌های موجود BFL، قابلیت‌ها و موارد استفاده بهینه برای تولید و ویرایش تصاویر پیشرفته را ارائه می‌دهد.

## مدل‌های موجود

Black Forest Labs مدل‌های پیشرفته تولید تصویر تحت خانواده FLUX ارائه می‌دهد که هر کدام برای نیازهای عملکرد و موارد استفاده مختلف طراحی شده‌اند.

### مدل‌های FLUX

خانواده FLUX نشان‌دهنده آخرین پیشرفت در تکنولوژی تولید تصویر است و سنتز تصاویر با کیفیت بالا با سطوح بهینه‌سازی مختلف ارائه می‌دهد.

### flux.2-pro

FLUX.2 Pro (`flux.2-pro`) پیشرفته‌ترین مدل تولید تصویر Black Forest Labs است با هوش بصری چندمرجعی، جزئیات بی‌سابقه، دقت رنگ و استدلال فضایی.

| ویژگی | جزئیات |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| نوع مدل | تولید تصویر |
| حداکثر رزولوشن | تا ۴ مگاپیکسل (۴۰۹۶x۴۰۹۶ پیکسل) |
| فرمت‌های پشتیبانی شده | PNG، JPEG |
| چندمرجعی | تا ۸ تصویر ورودی (API)، ۱۰ (playground) |
| ورودی | دستورات متنی، تصاویر مرجع |
| خروجی | تصاویر با کیفیت بالا |
| قیمت‌گذاری | $0.03 در هر مگاپیکسل (اولین MP)، $0.015 در هر MP اضافی |
| قیمت تصویر مرجع | $0.015 در هر مگاپیکسل |
| نقاط قوت | ترکیب چندمرجعی، دقت رنگ، تایپوگرافی، فوتوریالیسم |
| بهترین برای | بازاریابی محصول، پلتفرم‌های خلاق، تصاویر غذا، فیلم‌سازی |

> **⚠️ نکته مهم زبان:** FLUX.2 Pro برای دستورات انگلیسی بهینه شده است. برای بهترین نتایج، از دستورات انگلیسی هنگام تولید تصویر استفاده کنید. دستورات غیرانگلیسی ممکن است نتایج ناسازگار تولید کنند.

**قابلیت‌های کلیدی:**

- **چندمرجعی**: ترکیب عناصر از حداکثر ۸ تصویر با حفظ هویت در صحنه‌های پیچیده
- **فوتورئالیسم و جزئیات**: تولید تصاویر فوتورئالیستیک با جزئیات استثنایی
- **تایپوگرافی و متن**: تخصصی برای رندر متن و حفظ جزئیات کوچک
- **کنترل دقیق رنگ**: تطبیق دقیق رنگ هگز و دستورنویسی ساختاریافته

**نکات قیمت‌گذاری:**
- ۱ مگاپیکسل = ۱۰۲۴x۱۰۲۴ پیکسل
- رزولوشن همیشه به مگاپیکسل بعدی گرد می‌شود
- برای تصاویر مرجع متعدد، هر کدام جداگانه محاسبه می‌شود
- تصاویر بزرگتر از ۴ مگاپیکسل به ۴ مگاپیکسل تغییر اندازه می‌دهند

```python
from openai import OpenAI
import base64

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

response = client.images.generate(
    model="flux.2-pro",
    prompt="A professional headshot of a confident businesswoman in a modern office, soft natural lighting, shallow depth of field",
    size="1024x1024",
    n=1,
    response_format="b64_json",
)

# ذخیره تصویر
img_data = base64.b64decode(response.data[0].b64_json)
with open("professional_headshot.png", "wb") as f:
    f.write(img_data)
```

| ویژگی | جزئیات |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| نوع مدل | تولید تصویر |
| حداکثر رزولوشن | ۲۰۴۸x۲۰۴۸ پیکسل |
| فرمت‌های پشتیبانی شده | PNG، JPEG |
| ورودی | دستورات متنی |
| خروجی | تصاویر با کیفیت بالا |
| قیمت‌گذاری | $0.04 در هر تصویر |
| نقاط قوت | کیفیت تصویر برتر، پیروی عالی از دستورات، نتایج فوتوریالیستیک |
| بهترین برای | تولید تصویر حرفه‌ای، مواد بازاریابی، آثار هنری با کیفیت بالا |
| سرعت | زمان تولید استاندارد |

```python
from openai import OpenAI

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

response = client.images.generate(
    model="flux-1.1-pro",

    size="1024x1024",
    n=1,
    response_format="b64_json",  # از 'url' پشتیبانی نمی کند
)
```

### flux.1-kontext-pro

FLUX.1 Kontext Pro (`flux.1-kontext-pro`) مدل پیشرفته‌ای است که در ویرایش تصویر و تغییرات زمینه‌ای تخصص دارد و در عین حال کیفیت بالا را حفظ می‌کند.

| ویژگی | جزئیات |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| نوع مدل | تولید و ویرایش تصویر |
| حداکثر رزولوشن | ۲۰۴۸x۲۰۴۸ پیکسل |
| فرمت‌های پشتیبانی شده | PNG، JPEG |
| ورودی | دستورات متنی، تصاویر برای ویرایش |
| خروجی | تصاویر تولید شده یا ویرایش شده با کیفیت بالا |
| قیمت‌گذاری | $0.04 در هر تصویر |
| نقاط قوت | ویرایش آگاه از زمینه، تغییرات دقیق، حفظ انسجام تصویر |
| بهترین برای | ویرایش تصویر، انتقال سبک، تغییرات زمینه‌ای |
| ویژگی‌های خاص | قابلیت‌های پیشرفته تصویر به تصویر |

```python
from openai import OpenAI
import fs

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

# ویرایش تصویر
response = client.images.edit(
    model="flux.1-kontext-pro",
    image=fs.createReadStream("original_image.png"),
    prompt="آسمان را به غروب آفتاب دراماتیک تغییر دهید",
    size="1024x1024",
    n=1,
    response_format="b64_json",  # از 'url' پشتیبانی نمی کند
)
```

## قابلیت‌های کلیدی

### تولید تصویر پیشرفته

مدل‌های FLUX در ایجاد تصاویر با کیفیت بالا و فوتوریالیستیک با پیروی استثنایی از دستورات برتری دارند:

- **فوتوریالیسم**: تولید تصاویر بسیار واقعی که تشخیص آنها از عکس‌های واقعی دشوار است
- **سبک‌های هنری**: پشتیبانی از سبک‌های هنری مختلف و تفسیرهای خلاقانه
- **صحنه‌های پیچیده**: مدیریت صحنه‌های پیچیده چندشیء با روابط فضایی دقیق

### درک دستورات

مدل‌های Black Forest Labs دارای تفسیر پیچیده دستورات هستند:

- **زبان طبیعی**: درک توضیحات تفصیلی زبان طبیعی
- **دستورالعمل‌های سبک**: تفسیر دستورات سبک هنری و حالت
- **مشخصات فنی**: مدیریت اصطلاحات فنی عکاسی و هنر

### قابلیت‌های ویرایش تصویر

FLUX.1 Kontext Pro ویژگی‌های ویرایش پیشرفته ارائه می‌دهد:

- **حفظ زمینه**: حفظ انسجام تصویر در طول ویرایش
- **تغییرات انتخابی**: ایجاد تغییرات هدفمند بدون تاثیر بر کل تصویر
- **سازگاری سبک**: اطمینان از تطبیق ویرایش‌ها با سبک تصویر اصلی

## راهنمای انتخاب مدل

### انتخاب مدل FLUX مناسب

هنگام انتخاب مدل FLUX از طریق AvalAI، موارد زیر را در نظر بگیرید:

1. **نیازهای کیفیت**: از `flux-1.1-pro` برای بالاترین کیفیت تولید استفاده کنید
2. **نیازهای ویرایش**: از `flux.1-kontext-pro` برای ویرایش تصویر و تغییرات استفاده کنید
3. **مورد استفاده**: هر دو مدل نتایج حرفه‌ای با قیمت یکسان ارائه می‌دهند
4. **گردش کار**: در نظر بگیرید که آیا فقط به تولید یا قابلیت‌های ویرایش نیاز دارید

## اطلاعات قیمت‌گذاری

مدل‌های FLUX از طریق AvalAI با قیمت‌گذاری رقابتی در دسترس هستند:

| مدل | قیمت در هر تصویر |
|-------|----------------|
| flux-1.1-pro | $0.04 |
| flux.1-kontext-pro | $0.04 |

### نکات قیمت‌گذاری

- **نرخ ثابت**: قیمت‌گذاری ساده در هر تصویر بدون توجه به رزولوشن (تا حداکثر پشتیبانی شده)
- **بدون هزینه پنهان**: قیمت‌گذاری شفاف بدون هزینه اضافی
- **کیفیت حرفه‌ای**: نتایج سطح سازمانی با نرخ‌های رقابتی

### مقایسه عملکرد

| مورد استفاده | مدل FLUX توصیه شده | مدل‌های جایگزین |
| --------------------------------- | ----------------------------- | ------------------------------ |
| تولید تصویر با کیفیت بالا | flux-1.1-pro | gpt-image-2، Midjourney |
| ویرایش و تغییر تصویر | flux.1-kontext-pro | gpt-image-2 (edit)، Stable Diffusion |
| آثار هنری حرفه‌ای | flux-1.1-pro | gemini-3-pro-image، gpt-image-2 |
| مواد بازاریابی | flux-1.1-pro | gemini-3.1-flash-image، gpt-image-2 |
| پروژه‌های خلاقانه | flux.1-kontext-pro | Stable Diffusion، Midjourney |

## بهترین شیوه‌ها برای مدل‌های FLUX

### دستورالعمل‌نویسی مؤثر

توضیحات واضح و تفصیلی ارائه دهید. مدل‌های FLUX با دستورات مشخص در مورد سبک، ترکیب‌بندی و حالت عملکرد بهتری دارند.

```python
# مثال دستور خوب
prompt = "پرتره حرفه‌ای از یک زن کارآفرین در دفتر کار مدرن، نور طبیعی نرم، عمق میدان کم، گرفته شده با لنز ۸۵ میلی‌متری"

# به جای
prompt = "زن در دفتر کار"
```

### راهنمای ویرایش تصویر

هنگام استفاده از FLUX.1 Kontext Pro برای ویرایش:

1. **تغییرات را به وضوح توضیح دهید**: در مورد آنچه می‌خواهید تغییر دهید مشخص باشید
2. **زمینه را حفظ کنید**: اطمینان حاصل کنید که ویرایش‌ها با زمینه کلی تصویر مطابقت دارند
3. **نور را در نظر بگیرید**: شرایط نور موجود را در درخواست‌های ویرایش خود لحاظ کنید

### بهینه‌سازی کیفیت

- از دستورات تفصیلی برای نتایج بهتر استفاده کنید
- سبک و حالت مطلوب تصویر را مشخص کنید
- در صورت مرتبط بودن، اصطلاحات فنی عکاسی را شامل کنید
- برای ویرایش، رابطه بین عناصر جدید و موجود را توضیح دهید

## مثال‌های یکپارچه‌سازی

### تولید تصویر پایه

```python
from openai import OpenAI

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

response = client.images.generate(
    model="flux-1.1-pro",
    prompt="منظره شهری آینده‌نگرانه در شب با چراغ‌های نئون منعکس شده روی خیابان‌های خیس",
    size="1024x1024",
    quality="hd",
    n=1,
    response_format="b64_json",  # از 'url' پشتیبانی نمی کند
)
```

### گردش کار ویرایش تصویر

```python
import requests
from openai import OpenAI

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

# ویرایش تصویر موجود

```
