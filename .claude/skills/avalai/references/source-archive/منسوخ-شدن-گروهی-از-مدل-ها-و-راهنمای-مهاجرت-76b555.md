# منسوخ شدن گروهی از مدل‌ها و راهنمای مهاجرت

**Date:** ۱۴۰۵-۰۶-۱۳ / (2026-09-04)

## خلاصه

AvalAI مجموعه‌ای گسترده از مدل‌های منسوخ‌شده متعلق به OpenAI، Google، Anthropic، Stability AI و چند ارائه‌دهنده دیگر را از ۱۳ شهریور ۱۴۰۵ (۴ سپتامبر ۲۰۲۶) بازنشسته می‌کند. این اطلاعیه شناسه‌های مدل تحت‌تأثیر و جایگزین‌های پیشنهادی را فهرست می‌کند؛ از جمله خانواده GPT-5.6 برای چت OpenAI، خانواده تصویر «نانو بنانا» (Gemini) برای Imagen 4 و مدل‌های جدید صوتی برای TTS و رونویسی.

---

## جزئیات

OpenAI، Google، Anthropic و چند ارائه‌دهنده دیگر بازنشستگی گروه بزرگی از مدل‌ها را زمان‌بندی کرده یا تکمیل کرده‌اند. AvalAI فهرست مدل‌های خود را با این تغییرات upstream هماهنگ می‌کند، بنابراین درخواست‌هایی که از شناسه‌های منسوخ‌شده زیر استفاده کنند با خطا مواجه می‌شوند. این اطلاعیه مهم‌ترین موارد منسوخ‌شده را دسته‌بندی می‌کند و برای هر کدام یک جایگزین و مسیر مهاجرت مشخص ارائه می‌دهد.

برای فهرست کامل مدل‌های تحت‌تأثیر، همیشه به صفحه [مدل‌های منسوخ شده](fa/deprecations.md) مراجعه کنید؛ این صفحه منبع معتبر و پیوسته به‌روزرسانی‌شده است.

### مدل‌های چت GPT از OpenAI ← خانواده GPT-5.6

تگ‌های `-chat` خانواده GPT-5 و اسنپ‌شات‌های قدیمی‌تر چت GPT-5.x دیگر در دسترس نیستند. درخواست‌هایی که از `gpt-5-chat`، `gpt-5-chat-latest`، `gpt-5.1-chat`، `gpt-5.2-chat` یا `gpt-5.3-chat` استفاده کنند با خطا مواجه می‌شوند. از نام پایه مدل بدون `-chat` استفاده کنید و برای کارهای جدید به خانواده GPT-5.6 مهاجرت کنید.

| مدل منسوخ‌شده | مدل جایگزین |
| ------------- | ----------- |
| `gpt-5-chat` / `gpt-5-chat-latest` | `gpt-5.6-sol` |
| `gpt-5.1-chat` | `gpt-5.6-terra` |
| `gpt-5.2-chat` / `gpt-5.3-chat` | `gpt-5.6-sol` |
| `gpt-4o`، `gpt-4o-mini` (قدیمی) | `gpt-5.6-terra` / `gpt-5.6-luna` |

[خانواده GPT-5.6](fa/news/2026-07-10-gpt-5-6-grok-4-5-models-added.md) گزینه پیشنهادی فعلی برای چت عمومی و استدلال است:

- **`gpt-5.6-sol`** — توانمندترین مدل برای کدنویسی دشوار، تحلیل تخصصی و گردش‌کارهای عامل‌محور (حالت pro از طریق `reasoning.mode: pro`)
- **`gpt-5.6-terra`** — مدل متعادل برای استدلال روزمره و کارهای دانشی در محیط تولید
- **`gpt-5.6-luna`** — مدل کم‌هزینه برای کارهای پرحجم

console.log(completion.choices[0].message.content);

### مدل‌های تصویر Imagen 4 گوگل ← خانواده نانو بنانا (تصویر Gemini)

گوگل مدل‌های تولید تصویر Imagen 4 را منسوخ کرده است. گوگل خانواده نانو بنانا (تصویر بومی Gemini) را به‌عنوان جایگزین پیشنهاد می‌دهد.

| مدل منسوخ‌شده | مدل جایگزین |
| ------------- | ----------- |
| `imagen-4.0-generate-001` | `gemini-3.1-flash-image` (نانو بنانا ۲) |
| `imagen-4.0-ultra-generate-001` | `gemini-3-pro-image` (نانو بنانا پرو) |
| `imagen-4.0-fast-generate-001` | `gemini-3.1-flash-image` (نانو بنانا ۲) |
| `imagen-4.0-fast-generate-preview-06-06` | `gemini-3.1-flash-lite-image` (نانو بنانا ۲ لایت) |

راهنمای کامل را ببینید: [تولید و ویرایش تصویر با خانواده نانو بنانا](fa/examples/generate_images_with_nano_banana_series.md).

### مدل‌های TTS و رونویسی OpenAI ← مدل‌های صوتی جدید

OpenAI بازنشستگی مدل‌های قدیمی TTS و رونویسی خود را زمان‌بندی کرده است. مدل‌های منسوخ‌شده `tts-1`، `tts-1-hd`، `gpt-4o-mini-tts`، `whisper-1`، `gpt-4o-transcribe`، `gpt-4o-mini-transcribe` و `gpt-4o-transcribe-diarize` با مدل‌های جدید صوتی و رونویسی جایگزین می‌شوند.

| مدل منسوخ‌شده | مدل جایگزین |
| ------------- | ----------- |
| `gpt-4o-mini-tts`، `tts-1`، `tts-1-hd` | `gpt-audio-1.5` (یا Gemini TTS در ادامه) |
| `gpt-4o-transcribe`، `gpt-4o-mini-transcribe` | `gpt-transcribe` |
| `gpt-4o-transcribe-diarize` | `gpt-live-transcribe` |
| `whisper-1` | `gpt-transcribe` / `gpt-live-transcribe` |

برای برنامه‌های صوتی مکالمه‌ای، [ساخت برنامه‌های مکالمه‌ای با مدل‌های صوتی](fa/examples/building_conversational_apps_with_audio_models.md) را ببینید که از `gpt-audio-1.5`، `gpt-audio` و `gpt-audio-mini` با زنجیره `/v1/audio/speech` ← `/v1/responses` ← `/v1/audio/transcriptions` استفاده می‌کند. مدل‌های Gemini TTS (`gemini-2.5-pro-tts`، `gemini-2.5-flash-tts`) نیز برای گردش‌کارهایی که روی صوت Gemini استاندارد شده‌اند در دسترس هستند.

### سایر موارد منسوخ‌شده از ارائه‌دهندگان دیگر

طیف گسترده‌ای از مدل‌های دیگر نیز بازنشسته شده‌اند. جدول زیر رایج‌ترین آن‌ها را فهرست می‌کند؛ برای فهرست کامل به [مدل‌های منسوخ شده](fa/deprecations.md) مراجعه کنید.

| ارائه‌دهنده | منسوخ‌شده | مدل جایگزین |
| ----------- | --------- | ----------- |
| DeepSeek | `deepseek.r1-v1:0`، `deepseek-r1-0528`، `deepseek-v3-0324` | `deepseek-v4-flash` / `deepseek-v4-pro` |
| Groq | `groq.playai-tts`، `groq.playai-tts-arabic` | `gpt-audio-1.5` یا Gemini TTS |
| Mistral | `codestral-2501`، `mistral-ocr-2503`، `mistral-ocr-2505` | `mistral-ocr-4-0` / `mistral-ocr-latest` |
| Alibaba | `qwq-32b`، `qwen3-235b-a22b-thinking-2507` | `qwen3.5-plus` / `qwen3-8-max` |
| Moonshot | `kimi-k2-0905` | `kimi-k3` |
| Meta (Bedrock) | `meta.llama2-*`، `meta.llama3-*` | `llama-4-scout-17b-16e-instruct` |
| NVIDIA NIM | `nvidia_nim.*` (موارد منتخب) | برای مسیرهای فعلی NIM به `/v1/models` مراجعه کنید |
| Cloudflare | `cf.gemma-3-12b-it`، `cf.qwq-32b` | برای مسیرهای فعلی Cloudflare به `/v1/models` مراجعه کنید |

### روش مهاجرت

1. **شناسایی موارد استفاده**: کد خود را برای هر یک از شناسه‌های منسوخ‌شده بالا بررسی کنید.
2. **انتخاب جایگزین**: با استفاده از جدول‌های بالا مدل هدف را انتخاب کنید.
3. **به‌روزرسانی شناسه مدل**: فقط پارامتر `model` را تغییر دهید؛ endpointها و ساختار درخواست بدون تغییر باقی می‌مانند.
4. **آزمایش**: پیش از انتشار در محیط تولید، کیفیت، تأخیر و هزینه را با پرامپت‌های خود بررسی کنید.
5. **پین کردن برای تکرارپذیری**: وقتی به انتشار کنترل‌شده نیاز دارید، از شناسه صریح مدل (نه نام مستعار `-latest`) استفاده کنید.
