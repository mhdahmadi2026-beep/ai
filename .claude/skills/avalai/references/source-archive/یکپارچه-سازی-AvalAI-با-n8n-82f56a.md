# یکپارچه‌سازی AvalAI با n8n

n8n ابزاری قدرتمند برای اتوماسیون گردش کار متن‌باز است که امکان اتصال برنامه‌ها و سرویس‌های مختلف را فراهم می‌کند. با یکپارچه‌سازی AvalAI در n8n، می‌توانید به قدرت بیش از 410 مدل پیشرفته هوش مصنوعی دسترسی پیدا کرده و وظایفی نظیر تولید متن، خلاصه‌سازی، ترجمه، ایجاد تصویر، استدلال، تعبیه‌سازی و بسیاری موارد دیگر را به صورت خودکار انجام دهید.

این یکپارچه‌سازی بسیار ساده است: کافیست URL پایه را به `https://api.avalai.ir/v1` تغییر دهید و از کلید API AvalAI خود در n8n استفاده کنید. هیچ نیازی به تغییر در گردش کارها، اتوماسیون‌ها یا کدهای موجود شما نخواهد بود!

## چرا AvalAI را با n8n یکپارچه کنیم؟

یکپارچه‌سازی AvalAI با n8n به شما امکان می‌دهد طیف وسیعی از وظایف مبتنی بر هوش مصنوعی را خودکار کنید، از جمله:

* **دسترسی به بیش از 410 مدل:** از جدیدترین مدل‌های OpenAI، Anthropic، Google، XAI، DeepSeek، Alibaba، Moonshot.ai، Z.AI، MiniMax، Fireworks.ai، Mistral AI، Meta و سایر ارائه‌دهندگان، همگی از طریق یک API واحد و یکپارچه بهره‌مند شوید.
* **تولید محتوا:** مقالات، پست‌های وبلاگ، متون بازاریابی و سایر محتوای متنی را به صورت خودکار تولید کنید.
* **تحلیل داده:** داده‌های متنی را برای تحلیل احساسات، کلمات کلیدی و سایر بینش‌ها بررسی کنید.
* **توسعه چت‌بات:** چت‌بات‌های مجهز به هوش مصنوعی را برای خدمات مشتری یا سایر کاربردها بسازید و به کار گیرید.
* **ترجمه زبان:** متن را بین چندین زبان به صورت روان ترجمه کنید.
* **تولید تصویر:** با استفاده از مدل‌های مختلف موجود در AvalAI، تصاویر را از توضیحات متنی ایجاد کنید.
* **تولید کد:** تولید قطعه کد یا حتی برنامه‌های کامل را خودکار کنید.
* **مقرون به صرفه بودن و شفافیت:** قیمت‌گذاری AvalAI کاملا با نرخ‌های پایه API ارائه‌دهندگان اصلی همسو است (AvalAI هیچ سودی از خدمات پایه API نمی‌برد).

## شروع سریع: ساده‌ترین روش برای مبتدیان (گره HTTP Request) ⭐

> **این روش توصیه‌شده برای مبتدیان است!** این روش کاملا قابل اعتماد است و نیازی به پیکربندی پیچیده اعتبارنامه ندارد.

اگر تازه با n8n آشنا شده‌اید یا ساده‌ترین راه برای اتصال به AvalAI را می‌خواهید، از گره **HTTP Request** استفاده کنید. این روش ۱۰۰٪ کار می‌کند و راه‌اندازی آن بسیار آسان است.

### مرحله ۱: دریافت کلید API AvalAI

1. به [داشبورد AvalAI](https://chat.avalai.ir/platform/home) بروید، حساب بسازید و تلفن خود را تأیید کنید تا **۲۰۰٬۰۰۰ تومان اعتبار رایگان API** بگیرید. اگر ابتدا با ایمیل ثبت‌نام کنید، فورا **۲۵٬۰۰۰ تومان** و پس از اتصال و تأیید تلفن **۱۷۵٬۰۰۰ تومان دیگر** دریافت می‌کنید تا مجموع به ۲۰۰٬۰۰۰ تومان برسد.
2. به بخش "کلیدهای API" بروید
3. روی "ساخت کلید جدید" یا "Generate new secret key" کلیک کنید
4. **کلید را فورا کپی کنید** و در جایی امن ذخیره کنید

### مرحله ۲: افزودن گره HTTP Request به گردش کار

1. در گردش کار n8n خود، روی دکمه **+** کلیک کنید تا یک گره جدید اضافه کنید
2. عبارت **"HTTP Request"** را جستجو کنید و آن را انتخاب کنید
3. گره را با تنظیمات زیر پیکربندی کنید:

### مرحله ۳: پیکربندی گره HTTP Request

**تنظیمات اصلی:**
| تنظیم | مقدار |
|---------|-------|
| **Method** | `POST` |
| **URL** | `https://api.avalai.ir/v1/chat/completions` |

**احراز هویت (Authentication):**
| تنظیم | مقدار |
|---------|-------|
| **Authentication** | `Generic Credential Type` |
| **Generic Auth Type** | `Header Auth` |
| **Credential Name** | یک اعتبارنامه جدید بسازید و نام "AvalAI API" را بگذارید |
| **Name** | `Authorization` |
| **Value** | `Bearer YOUR_API_KEY_HERE` |

> ⚠️ **مهم:** عبارت `YOUR_API_KEY_HERE` را با کلید API واقعی خود جایگزین کنید. کلمه "Bearer" و یک فاصله قبل از کلید را حفظ کنید.

**هدرها (Headers):**
| نام هدر | مقدار هدر |
|-------------|--------------|
| `Content-Type` | `application/json` |

**بدنه درخواست (Body):**
- گزینه **Body Content Type** را روی `JSON` قرار دهید
- این JSON را در بدنه اضافه کنید:

```json
{
  "model": "gpt-5.4-mini",
  "messages": [
    {
      "role": "user",
      "content": "سلام! یک جوک بگو."
    }
  ]
}
```

### مرحله ۴: تست اتصال

1. روی **"Execute Node"** یا **"Test Step"** کلیک کنید
2. باید یک پاسخ با جواب هوش مصنوعی ببینید
3. اگر موفق بود، متصل شدید! 🎉

### مثال: استفاده از ورودی پویا

برای استفاده از ورودی گره‌های قبلی، بدنه را به این شکل تغییر دهید:

```json
{
  "model": "gpt-5.4-mini",
  "messages": [
    {
      "role": "system",
      "content": "تو یک دستیار مفید هستی."
    },
    {
      "role": "user",
      "content": "{{ $json.userMessage }}"
    }
  ]
}
```

این کد فیلد `userMessage` را از خروجی گره قبلی می‌گیرد.

برای endpoint مربوط به Responses، بدنه dynamic معادل این است:

```json
{
  "model": "gpt-5.6-luna",
  "instructions": "تو یک دستیار مفید هستی.",
  "input": "{{ $json.userMessage }}"
}
```

## دریافت کلید API AvalAI برای n8n (راهنمای گام به گام)

برای دریافت کلید API AvalAI خود، مراحل زیر را دنبال کنید:

1. **ایجاد و تأیید حساب AvalAI:**
 اگر هنوز حساب ندارید، به [داشبورد AvalAI](https://chat.avalai.ir/platform/home) بروید. ثبت‌نام با شمارهٔ تلفن و تأیید آن، **۲۰۰٬۰۰۰ تومان اعتبار رایگان API** ارائه می‌دهد. اگر با ایمیل شروع کنید، ابتدا **۲۵٬۰۰۰ تومان** و پس از اتصال و تأیید تلفن **۱۷۵٬۰۰۰ تومان دیگر** دریافت می‌کنید تا مجموع اعتبار رایگان به ۲۰۰٬۰۰۰ تومان برسد. برای دریافت این اعتبار ثبت‌نام نیازی به شارژ نیست.

2. **دسترسی به بخش کلیدهای API:**
پس از ورود به حساب کاربری، به بخش "کلید‌های API" در داشبورد خود بروید.

3. **ساخت کلید جدید:**
در صفحه کلیدهای API، روی دکمه یا گزینه "ساخت کلید جدید" یا "Generate new secret key" کلیک کنید.

4.  **نام‌گذاری کلید (اختیاری):**
    ممکن است از شما خواسته شود که یک نام توصیفی برای کلید API خود انتخاب کنید. این کار برای سازماندهی و مدیریت کلیدهای شما در آینده مفید است.

5.  **کپی کردن کلید API:**
    پس از تولید کلید، به شما نمایش داده خواهد شد. **مهم:** این کلید را بلافاصله کپی کرده و در مکانی امن ذخیره کنید. به دلایل امنیتی، دیگر نمی‌توانید کلید کامل را مشاهده کنید.

## پیکربندی n8n برای AvalAI

AvalAI سازگاری با چندین ارائه‌دهنده هوش مصنوعی را از طریق نود‌های اختصاصی در n8n فراهم می‌کند. شما می‌توانید از نود‌های یکپارچه‌سازی OpenAI، Google Gemini (PaLM) و Anthropic استفاده کنید که هر کدام برای کار با API یکپارچه AvalAI پیکربندی شده‌اند.

### تنظیم اعتبارنامه‌های گره OpenAI

1.  در نمونه n8n خود، به بخش "Credentials" بروید.
2.  یک اعتبارنامه جدید از نوع "OpenAI" اضافه کنید.
3.  کلید API AvalAI را که قبلا کپی کرده‌اید، در فیلد "API Key" جای‌گذاری کنید.
4.  نکته مهم، در فیلد "Base URL" یا "Custom URL" (نام دقیق ممکن است بسته به نسخه n8n متفاوت باشد)، `https://api.avalai.ir/v1` را وارد کنید.
5.  اعتبارنامه‌های خود را نام‌گذاری کنید (به عنوان مثال، "اتصال AvalAI OpenAI")، آن‌ها را ذخیره کنید و سپس به گردش کار خود بازگردید تا اعتبارنامه تازه ایجاد شده را از لیست کشویی انتخاب کنید.

### تنظیم اعتبارنامه‌های گره Google Gemini (PaLM)

1.  در نمونه n8n خود، به بخش "Credentials" بروید.
2.  روی "Add new credential" کلیک کنید و نوع اعتبارنامه با نام **"Google Gemini(PaLM) Api"** را از لیست انتخاب کنید.
3.  کلید API AvalAI خود را در فیلد "API Key" وارد کنید.
4.  در فیلد "Host" یا "Base URL"، `https://api.avalai.ir` را وارد کنید.
5.  اعتبارنامه‌های خود را نام‌گذاری کنید (به عنوان مثال، "اتصال AvalAI Gemini") و آن‌ها را ذخیره کنید.

### تنظیم اعتبارنامه‌های گره Anthropic

1.  در نمونه n8n خود، به بخش "Credentials" بروید.
2.  یک اعتبارنامه جدید از نوع "Anthropic" اضافه کنید.
3.  کلید API AvalAI خود را در فیلد "API Key" وارد کنید.
4.  در فیلد "Host" یا "Base URL"، `https://api.avalai.ir` را وارد کنید.
5.  اعتبارنامه‌های خود را نام‌گذاری کنید (به عنوان مثال، "اتصال AvalAI Anthropic") و آن‌ها را ذخیره کنید.

### استفاده از گره‌های یکپارچه‌سازی هوش مصنوعی با AvalAI

هر گره ارائه‌دهنده هوش مصنوعی در n8n هنگامی که با اعتبارنامه‌های مناسب پیکربندی شود، به طور یکپارچه با AvalAI کار می‌کند. در ادامه نحوه استفاده مؤثر از هر کدام آورده شده است:

#### گره OpenAI - دسترسی یکپارچه به بیش از 410 مدل

گره OpenAI هنگام اتصال به AvalAI، گسترده‌ترین دسترسی به مدل‌ها را فراهم می‌کند:

*   **سازگاری مدل:** با **تمامی 410+ مدل** موجود در AvalAI کار می‌کند، شامل OpenAI، Anthropic، Google، Mistral، Meta و بسیاری از ارائه‌دهندگان دیگر
*   **چت:** برای وظایف هوش مصنوعی مکالمه‌ای با مدل‌هایی مانند `gpt-5.5`، `gpt-5.4-mini`، `claude-opus-4-8`، `claude-sonnet-4-6`، `gemini-3.5-flash`، `grok-4.3`، `deepseek-v4-pro`، `qwen3.7-max`، `kimi-k2.7-code`، `glm-5.2`، `nemotron-3-ultra` و `minimax-m3` استفاده کنید
*   **تصویر:** با استفاده از `gpt-image-2`، `gpt-image-1.5`، `qwen-image-2.0-pro`، `qwen-image-2.0`، `gemini-3.1-flash-image`، `seedream-5-0-260128`، DALL·E 3 یا مدل‌های Stability AI تصاویر ایجاد کنید
*   **متن:** در حالی که عملیات قدیمی "Completions" در دسترس است، منبع "Chat" برای وظایف متنی مدرن توصیه می‌شود

#### گره Google Gemini (PaLM) - خانواده مدل‌های Gemini

گره Gemini برای مدل‌های هوش مصنوعی Google تخصصی شده است:

*   **سازگاری مدل:** به طور خاص با **خانواده مدل‌های Gemini** کار می‌کند (`gemini-3.5-flash`، `gemini-3.1-pro-preview`، `gemini-3.1-flash-lite`، `gemini-2.5-pro`، `gemini-2.5-flash` و غیره)
*   **عملکرد بهینه:** به طور خاص برای مدل‌های Gemini با پشتیبانی پارامترهای بومی طراحی شده است
*   **موارد استفاده:** زمانی که به طور خاص به مدل‌های Gemini برای قابلیت‌های منحصر به فردشان نیاز دارید، ایده‌آل است

> ⚠️ **مهم - فرمت نام مدل:** هنگام استفاده از گره بومی Gemini (PaLM) در n8n، **تمامی نام‌های مدل Gemini باید با پیشوند `models/` شروع شوند** در فیلد "Model". گره Gemini در n8n این پیشوند را به صورت خودکار اضافه نمی‌کند، اما اندپوینت API Gemini به آن نیاز دارد (مثلا `v1beta/models/gemini-2.5-flash:generateContent`).
>
> **این برای تمامی مدل‌های Gemini صدق می‌کند**، از جمله:
> - `gemini-2.5-flash` → `models/gemini-2.5-flash`
> - `gemini-2.5-pro` → `models/gemini-2.5-pro`
> - `gemini-3.5-flash` → `models/gemini-3.5-flash`
> - `gemini-3.1-pro-preview` → `models/gemini-3.1-pro-preview`
> - `gemini-3.1-flash-lite-preview` → `models/gemini-3.1-flash-lite-preview`
>
> **اگر خطای 404 دریافت کردید**، اطمینان حاصل کنید که پیشوند `models/` قبل از نام مدل شما وجود دارد.
>
> **مثال:**
> - ❌ `gemini-2.5-flash` → منجر به خطای 404 می‌شود
> - ✅ `models/gemini-2.5-flash` → فرمت صحیح

#### گره Anthropic - Anthropic به علاوه پشتیبانی گسترده از مدل‌ها

گره Anthropic سازگاری گسترده‌ای فراتر از مدل‌های Anthropic ارائه می‌دهد:

*   **سازگاری مدل:** با **تمامی مدل‌های Anthropic** به علاوه **اکثر مدل‌های دیگر** موجود در AvalAI کار می‌کند
*   **پشتیبانی در حال گسترش:** سازگاری مدل‌ها به طور مداوم بهبود می‌یابد و به سمت پشتیبانی از تمامی مدل‌های موجود پیش می‌رود
*   **یکپارچه‌سازی Claude:** برای `claude-opus-4-8`، `claude-opus-4-7`، `claude-sonnet-4-6`، `claude-haiku-4-5` و سایر مدل‌های Anthropic عالی است
*   **مدل‌های اضافی:** همچنین از بسیاری از مدل‌های غیر Anthropic برای انعطاف‌پذیری پشتیبانی می‌کند

#### پرامپت‌نویسی با منبع چت

درست مانند API استاندارد OpenAI، یکپارچه‌سازی n8n برای چت به شما امکان می‌دهد نقش‌ها را تعریف کنید: دستیار (Assistant)، سیستم (System) و کاربر (User).

*   **دستیار (Assistant):** نشان‌دهنده پاسخ‌های قبلی هوش مصنوعی در یک مکالمه است.
*   **سیستم (System):** دستورالعمل‌ها یا زمینه‌ی اولیه را برای تعریف رفتار اساسی هوش مصنوعی فراهم می‌کند. یک پرامپت سیستمی خوب می‌تواند به طور قابل توجهی مورد استفاده هوش مصنوعی شما را بهبود بخشد.
*   **کاربر (User):** شامل ورودی کاربر یا وظیفه خاص برای هوش مصنوعی است.

## نکات و بهترین شیوه‌ها

*   **ذخیره‌سازی امن:** کلید API AvalAI خود را مانند یک رمز عبور در نظر بگیرید. آن را به صورت امن ذخیره کرده و به صورت عمومی به اشتراک نگذارید.
*   **مدیریت کلید:** برای پروژه‌های متعدد یا موارد استفاده مختلف، کلیدهای API جداگانه را در داشبورد AvalAI خود ایجاد کنید تا سازماندهی و کنترل را حفظ کنید.
* **محدودیت‌های نرخ:** از [محدودیت‌های نرخ AvalAI](/fa/guides/rate-limits.md) آگاه باشید. استراتژی‌هایی مانند افزودن تاخیر یا استفاده از صف‌ها در گردش کارهای n8n خود را برای مدیریت مؤثر درخواست‌های API و جلوگیری از رسیدن به محدودیت‌ها پیاده‌سازی کنید.
* **ملاحظات هزینه:** همانطور که پیش‌تر ذکر شد، قیمت‌گذاری AvalAI **۱۰۰٪ با نرخ‌های پایه API ارائه‌دهندگان همسو است**. برای درک دقیق‌تر هزینه‌های مربوط به استفاده، [صفحه قیمت‌گذاری AvalAI](/fa/pricing.md) را بررسی کنید.
* **مستندات n8n:** برای دستورالعمل‌های خاص و نکات عیب‌یابی مربوط به یکپارچه‌سازی OpenAI، به مستندات رسمی n8n مراجعه کنید، زیرا عملکرد اصلی یکسان است.

## عیب‌یابی

*   **کلید API نامعتبر:** اگر با خطای "invalid API key" مواجه شدید، دوباره بررسی کنید که کلید AvalAI خود را به درستی کپی کرده‌اید و در فیلد API Key در n8n وارد شده است.
*   **مشکلات اتصال:** اطمینان حاصل کنید که نمونه n8n شما به اینترنت دسترسی دارد و هیچ فایروال یا محدودیت شبکه‌ای اتصال به آدرس‌های زیر را مسدود نمی‌کند:
    - `https://api.avalai.ir/v1` (برای گره OpenAI)
    - `https://api.avalai.ir` (برای گره‌های Gemini و Anthropic)
*   **URL پایه اشتباه:** مطمئن شوید که از URL پایه صحیح برای هر نوع گره استفاده می‌کنید:
    - گره OpenAI نیاز به مسیر `/v1` دارد: `https://api.avalai.ir/v1`
    - گره‌های Gemini و Anthropic از: `https://api.avalai.ir` استفاده می‌کنند
*   **سازگاری مدل:** اگر مدل خاصی با گره مشخصی کار نمی‌کند، سعی کنید از گره OpenAI استفاده کنید که از تمامی 410+ مدل موجود در AvalAI پشتیبانی می‌کند. برای گره‌های بومی Gemini، فراموش نکنید نام مدل را با پیشوند `models/` وارد کنید.
*   **خطاهای محدودیت نرخ:** اگر خطاهای محدودیت نرخ دریافت کردید، فرکانس درخواست گردش کار خود را بررسی کنید. برای کاهش بار، تاخیر یا دسته‌بندی را پیاده‌سازی کنید.

## نتیجه‌گیری

دریافت کلید API AvalAI و پیکربندی آن در n8n فرآیندی ساده است که به شما امکان می‌دهد قدرت بیش از 410 مدل هوش مصنوعی را مستقیما در گردش کارهای اتوماسیون خود به کار گیرید. با دنبال کردن این مراحل، می‌توانید جدیدترین قابلیت‌های هوش مصنوعی AvalAI را برای متن، استدلال، کدنویسی، تصویر، تعبیه‌سازی و جستجو به طور یکپارچه در اتوماسیون‌های خود ادغام کنید. امروز شروع به کاوش امکانات کنید!
