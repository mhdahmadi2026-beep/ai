# Seedream 4.0: مدل پیشرفته تولید تصویر اکنون در دسترس است

**تاریخ:** 1404-07-09

اعلام می‌کنیم که **Seedream 4.0** (`seedream-4-0-250828`)، جدیدترین مدل پیشرفته تولید و ویرایش تصویر از ByteDance، اکنون از طریق ادغام جدید ارائه‌دهنده **BytePlus** در AvalAI در دسترس است.

## Seedream 4.0 چیست؟

Seedream 4.0 نمایانگر پیشرفت قابل توجهی در فناوری تولید تصویر با هوش مصنوعی است. این مدل که توسط ByteDance توسعه یافته و از طریق پلتفرم BytePlus قابل دسترسی است، قابلیت‌های بی‌نظیری برای وظایف تولید متن-به-تصویر و ویرایش تصویر-به-تصویر ارائه می‌دهد.

> **نکته مهم**: برای بهترین نتایج، توصیه می‌شود از پرامپت‌های انگلیسی استفاده کنید زیرا مدل‌های تولید تصویر معمولا برای زبان انگلیسی بهینه‌سازی شده‌اند.

## ویژگی‌ها و قابلیت‌های کلیدی

### 🎨 **حالت‌های تولید پیشرفته**
- **تولید تصویر منفرد**: تصاویر با کیفیت بالا از پرامپت‌های متنی
- **تولید تصویر متوالی**: تولید دسته‌ای از تصاویر مرتبط موضوعی (تا 15 تصویر)
- **ترکیب چند تصویر**: ترکیب چندین تصویر مرجع (2-10) با پرامپت‌های متنی
- **ویرایش تصویر-به-تصویر**: تبدیل تصاویر موجود با راهنمایی متنی

### 🚀 **برتری فنی**
- **پشتیبانی از وضوح بالا**: تولید تصاویر تا وضوح 4K (4096x4096 پیکسل)
- **نسبت‌های ابعاد انعطاف‌پذیر**: پشتیبانی از نسبت‌های مختلف از 1:16 تا 16:1
- **فرمت‌های ورودی متعدد**: پشتیبانی از ورودی تصویر Base64 و URL
- **خروجی جریانی**: تولید تصویر بلادرنگ با نتایج تدریجی

### ⚡ **پارامترهای پیشرفته**
- **کنترل تولید متوالی**: تولید دسته‌ای خودکار با محدودیت‌های قابل تنظیم
- **گزینه‌های واترمارک**: واترمارک‌های اختیاری تولید شده با AI
- **فرمت‌های پاسخ**: فرمت‌های خروجی URL و Base64 JSON
- **مشخصات اندازه**: پشتیبانی از پیش‌تنظیمات وضوح 1K، 2K و 4K

## قیمت‌گذاری

Seedream 4.0 با قیمت **0.03 دلار به ازای هر تصویر** برای عملیات تولید و ویرایش در دسترس است و یکی از مقرون‌به‌صرفه‌ترین مدل‌های پریمیوم تولید تصویر موجود محسوب می‌شود.

## شروع کار

### تولید پایه متن-به-تصویر

```python
from openai import OpenAI

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

response = client.images.generate(
    model="seedream-4-0-250828",
    prompt="A futuristic cityscape at sunset with flying cars and neon lights",
    size="4K",
    response_format="url",
    extra_body={"sequential_image_generation": "disabled", "watermark": False},
)

print(f"Generated image: {response.data[0].url}")
```

### ویرایش تصویر-به-تصویر

```python
response = client.images.edit(
    model="seedream-4-0-250828",
    image=open("input_image.png", "rb"),
    prompt="Transform this into a cyberpunk style artwork",
    size="2K",
    response_format="url",
    extra_body={"sequential_image_generation": "disabled", "watermark": False},
)

print(f"Edited image: {response.data[0].url}")
```

### تولید تصویر متوالی

```python
response = client.images.generate(
    model="seedream-4-0-250828",
    prompt="A series of landscape paintings showing the four seasons",
    size="2K",
    extra_body={
        "sequential_image_generation": "auto",
        "sequential_image_generation_options": {"max_images": 4},
        "watermark": False,
    },
)

for i, image in enumerate(response.data):
    print(f"Season {i+1}: {image.url}")
```

## موارد استفاده

Seedream 4.0 در کاربردهای مختلف عملکرد فوق‌العاده‌ای دارد:

- **تولید محتوای خلاقانه**: آثار هنری با کیفیت بالا، تصاویر و آثار مفهومی
- **مواد بازاریابی**: تجسم محصولات، گرافیک‌های تبلیغاتی و دارایی‌های برند
- **بهبود محتوا**: ویرایش تصویر، انتقال سبک و بهبودهای بصری
- **پردازش دسته‌ای**: ایجاد مجموعه‌ای از تصاویر مرتبط برای داستان‌سرایی یا کمپین‌ها
- **نمونه‌سازی**: تجسم سریع ایده‌ها و مفاهیم

## بهترین شیوه‌ها

1. **پرامپت‌های تفصیلی**: از پرامپت‌های توصیفی (تا 600 کلمه انگلیسی) برای بهترین نتایج استفاده کنید
2. **برنامه‌ریزی وضوح**: وضوح مناسب را بر اساس مورد استفاده خود انتخاب کنید
3. **تولید متوالی**: از تولید دسته‌ای برای سری تصاویر مرتبط استفاده کنید
4. **کیفیت تصویر**: اطمینان حاصل کنید تصاویر ورودی الزامات فرمت را برآورده می‌کنند (JPEG/PNG، حداکثر 10MB)
5. **نسبت‌های ابعاد**: هنگام انتخاب ابعاد، فرمت نمایش مورد نظر را در نظر بگیرید

## ادغام با AvalAI

Seedream 4.0 به‌طور یکپارچه با API یکپارچه AvalAI ادغام می‌شود و پشتیبانی می‌کند از:

- **SDK سازگار با OpenAI**: از کتابخانه‌های کلاینت آشنای OpenAI استفاده کنید
- **تماس‌های مستقیم API**: دسترسی RESTful API با endpoint های استاندارد
- **فرمت‌های متعدد**: پشتیبانی از `v1/images/generations` و `v1/images/edits`
- **پشتیبانی جریانی**: تولید تصویر بلادرنگ با به‌روزرسانی‌های تدریجی

## آینده چه خواهد بود؟

این اضافه تعهد AvalAI به ارائه دسترسی به جدیدترین و پیشرفته‌ترین مدل‌های AI را نشان می‌دهد. Seedream 4.0 به مجموعه جامع مدل‌های تولید تصویر ما می‌پیوندد و انتخاب‌های بیشتری را برای نیازهای خاص توسعه‌دهندگان و خالقان فراهم می‌کند.
