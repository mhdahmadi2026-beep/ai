# مدل‌های جدید: Eleven v3، Kimi k2.5 و به‌روزرسانی‌های Qwen3

**تاریخ:** ۱۴۰۴-۱۱-۱۶ / (2026-02-05)

## خلاصه

ما پشتیبانی از مدل **Eleven v3** از ElevenLabs، مدل **Kimi k2.5** از Moonshot AI، و مدل **Qwen3-Rerank** از Alibaba را اضافه کردیم. همچنین مدل‌های **Qwen3-Max** و **Qwen3-VL-Flash** را با آخرین نسخه‌های خود به‌روزرسانی کردیم که عملکرد بهبود یافته‌ای با همان قیمت ارائه می‌دهند.

---

## جزئیات

### ElevenLabs

#### Eleven v3
**Eleven v3** (`eleven_v3`) پیشرفته‌ترین مدل سنتز گفتار ElevenLabs است که گفتار زنده و احساسی تولید می‌کند. این مدل از مکالمه چند گوینده طبیعی پشتیبانی می‌کند و درک متنی بالایی دارد.

- **Endpoint**: `v1/audio/speech`
- **قابلیت‌ها**: بازه احساسی بالا، پشتیبانی از مکالمه چند گوینده، بیش از ۷۰ زبان.
- **قیمت**: ۰.۰۰۵ دلار به ازای هر ثانیه صوت تولید شده.

**جزئیات قیمت‌گذاری:**

| مدل | ورودی | ورودی کش شده | خروجی | واحد قیمت‌گذاری |
|-------|-------|--------------|--------|--------------|
| eleven_v3 | - | - | - | ۰.۰۰۵ دلار / ثانیه |

#### نمونه درخواست

```bash
curl https://api.avalai.ir/v1/audio/speech \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "eleven_v3",
    "input": "این یک نمونه از مدل جدید Eleven v3 است.",
    "voice": "coral"
  }' \
  --output test_audio.mp3
```

### Moonshot AI

#### Kimi k2.5
**Kimi k2.5** (`kimi-k2.5`) یک مدل چندوجهی قدرتمند از Moonshot AI است که برای استدلال پیشرفته، کدنویسی و وظایف عاملی طراحی شده است. این مدل در گردش‌های کاری پیچیده عالی عمل می‌کند و از قابلیت‌های بینایی پشتیبانی می‌کند.

- **Endpoints**: `v1/chat/completions`, `v1/responses`
- **قابلیت‌ها**: استدلال پیشرفته، کدنویسی، بینایی، رفتار عاملی.

**جزئیات قیمت‌گذاری:**

| مدل | ورودی | ورودی کش شده | خروجی |
|-------|-------|--------------|--------|
| kimi-k2.5 | ۰.۶۶ دلار | ۰.۱۱ دلار | ۳.۳۰ دلار |
*(قیمت‌ها به ازای هر ۱ میلیون توکن)*

#### نمونه درخواست

```bash
curl https://api.avalai.ir/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -d '{
    "model": "kimi-k2.5",
    "messages": [
      {
        "role": "user",
        "content": "اهمیت مدل Kimi k2.5 را توضیح دهید."
      }
    ]
  }'
```

#### نمونه پاسخ

```json
{
  "id": "chatcmpl-kimi-example",
  "created": 1709673400,
  "model": "kimi-k2.5",
  "object": "chat.completion",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Kimi k2.5 یک پیشرفت قابل توجه در..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 25,
    "total_tokens": 37
  }
}
```

### Alibaba

#### Qwen3 Rerank
**Qwen3 Rerank** (`qwen3-rerank`) یک مدل تخصصی برای رتبه‌بندی مجدد اسناد متنی است که برای برنامه‌های RAG (بازیابی تقویت شده با تولید) ضروری است تا دقت بازیابی را بهبود بخشد.

- **Endpoint**: `v1/rerank`
- **قابلیت‌ها**: رتبه‌بندی مجدد متن با دقت بالا، پشتیبانی از بیش از ۱۰۰ زبان.

**جزئیات قیمت‌گذاری:**

| مدل | ورودی | ورودی کش شده | خروجی |
|-------|-------|--------------|--------|
| qwen3-rerank | ۰.۱۰ دلار | ۰.۰۰۳۵ دلار | - |
*(قیمت‌ها به ازای هر ۱ میلیون توکن)*

#### نمونه درخواست

```bash
curl https://api.avalai.ir/v1/rerank \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -d '{
    "model": "qwen3-rerank",
    "query": "یادگیری ماشین چیست؟",
    "documents": [
      "یادگیری ماشین یک حوزه مطالعاتی است...",
      "یادگیری عمیق زیرمجموعه‌ای از یادگیری ماشین است...",
      "سیب نوعی میوه است..."
    ]
  }'
```

#### به‌روزرسانی‌های مدل Qwen3
همچنین مدل‌های Qwen3 زیر را به آخرین نسخه‌های خود به‌روزرسانی کردیم. این به‌روزرسانی‌ها عملکرد بهبود یافته‌ای را با حفظ همان قیمت‌گذاری ارائه می‌دهند.

- **Qwen3 Max**: به‌روزرسانی به `qwen3-max-2026-01-23`
- **Qwen3 VL Flash**: به‌روزرسانی به `qwen3-vl-flash-2026-01-22`

می‌توانید از این نام‌های نسخه خاص برای قفل کردن برنامه خود به این نسخه‌ها استفاده کنید، یا به استفاده از نام‌های مدل پایه (`qwen3-max`, `qwen3-vl-flash`) ادامه دهید تا به طور خودکار از آخرین نسخه‌های پایدار استفاده کنید.

**جزئیات قیمت‌گذاری (مانند نسخه‌های قبلی):**

| مدل | ورودی | ورودی کش شده | خروجی | قیمت‌گذاری ویژه |
|-------|-------|--------------|--------|-----------------|
| qwen3-max-2026-01-23 | ۱.۲۰ دلار | ۰.۱۰ دلار | ۶.۰۰ دلار | نرخ‌های بالاتر برای >32K و >128K context |
| qwen3-vl-flash-2026-01-22 | ۰.۰۵ دلار | ۰.۰۱ دلار | ۰.۴۰ دلار | نرخ‌های بالاتر برای >32K و >128K context |

*(قیمت‌ها به ازای هر ۱ میلیون توکن. برای جزئیات سطوح context به صفحه قیمت‌گذاری مراجعه کنید.)*
