# به‌روزرسانی‌های داشبورد و مدل Gemini 2.5 Flash

**تاریخ:** 1404-03-01 / (2025-05-22)

## خلاصه

ما با افتخار به‌روزرسانی‌های مهمی را در پلتفرم AvalAI اعلام می‌کنیم، از جمله حفاظ‌های امنیتی (Guardrails) جدید برای محافظت از اطلاعات حساس در درخواست‌های API، ویژگی‌های جدید داشبورد کاربری برای تنظیم آستانه‌های سفارشی هشدار اعتبار و مدیریت اطلاع‌رسانی، به علاوه آخرین به‌روزرسانی مدل Gemini 2.5 Flash با عملکرد بهبود یافته و قابلیت‌های جدید.

---

## جزئیات

### بهبودهای داشبورد

#### آستانه‌های سفارشی هشدار اعتبار

ما داشبورد کاربری را با قابلیت تنظیم آستانه‌های سفارشی هشدار اعتبار ارتقا داده‌ایم. این ویژگی به شما امکان می‌دهد:

- آستانه‌های اطلاع‌رسانی شخصی‌سازی شده برای مانده اعتبار خود تعریف کنید
- هشدارهای به‌موقع دریافت کنید وقتی اعتبار شما به سطوح مشخص شده می‌رسد
- از میان آستانه‌های پیش‌فرض انتخاب کنید یا مقادیر سفارشی خود را تنظیم نمایید

قبلا، کاربران محدود به مقادیر آستانه از پیش تعیین شده بودند. اکنون، می‌توانید مقادیر دقیق اعتباری را مشخص کنید که برای الگوهای استفاده و برنامه‌ریزی بودجه شما معنادار است.

داشبورد اکنون گزینه‌های آستانه پیش‌فرض زیر را شامل می‌شود:

- 1.00 واحد
- 5.00 واحد
- 20.00 واحد
- 50.00 واحد

یا می‌توانید آستانه‌های سفارشی خود را که با نیازهای خاص شما مطابقت دارند، تنظیم کنید.

#### دریافت‌کنندگان اضافی هشدار

برای کاربران سطح 5، ما قابلیت تعیین تا دو دریافت‌کننده اضافی برای اطلاع‌رسانی‌های هشدار اعتبار را اضافه کرده‌ایم:

- تا 2 آدرس ایمیل اضافی اضافه کنید
- تا 2 شماره تلفن اضافی اضافه کنید
- اطمینان حاصل کنید که تیم شما از استفاده اعتبار مطلع می‌ماند

این ویژگی به تیم‌ها کمک می‌کند تا استفاده از اعتبار خود را بهتر مدیریت کنند با اطلاع‌رسانی به ذینفعان مربوطه درباره مانده اعتبار بدون نیاز به ورود آن‌ها به داشبورد.

### حفاظ‌های امنیتی جدید (Guardrails)

در AvalAI، امنیت را در اولویت اول قرار می‌دهیم. با افتخار سیستم حفاظ‌های امنیتی (Guardrails) جدید خود را معرفی می‌کنیم که به محافظت از درخواست‌های API شما با تشخیص و حذف خودکار اطلاعات حساس مانند کلیدهای API و توکن‌ها کمک می‌کند:

- **تشخیص خودکار**: تمام درخواست‌های API می‌توانند از طریق سیستم detect-secrets ما پردازش شوند
- **محافظت از داده‌های حساس**: کلیدهای API، توکن‌ها و سایر اطلاعات حساس با [REDACTED] جایگزین می‌شوند
- **بدون لاگ‌های حساس**: این فرآیند هیچ لاگی از داده‌های حساس پاک‌سازی شده باقی نمی‌گذارد

#### نحوه عملکرد

سیستم حفاظ امنیتی ما از [Yelp/detect-secrets](https://github.com/Yelp/detect-secrets)، یک پروژه متن‌باز که به طور خاص برای تشخیص و پاک‌سازی داده‌های حساس در درخواست‌های API شما طراحی شده، استفاده می‌کند. هنگامی که سیستم اطلاعات حساس را تشخیص می‌دهد، به طور خودکار آن را با [REDACTED] قبل از رسیدن درخواست به مدل‌های LLM جایگزین می‌کند و لایه امنیتی اضافی برای داده‌های شما فراهم می‌آورد.

#### گزینه‌های فعال‌سازی

شما می‌توانید Guardrails را به دو روش فعال کنید:

1. **فعال‌سازی در سطح کاربر**: در تنظیمات کاربری خود فعال کنید تا تمام درخواست‌های API به طور خودکار اسکن و محافظت شوند
2. **فعال‌سازی برای درخواست خاص**: `guardrails: ["hide-secrets"]` را در داده‌های درخواست API برای تماس‌های خاص قرار دهید

#### مثال

```json
// درخواست اصلی با داده‌های حساس

{
  "messages": [
    {
      "role": "user",
      "content": "مقدار کلید api من چیست؟ api_key=sk-8nasdnAUna9nasndania"
    }
  ],
  "guardrails": ["hide-secrets"]
}
// درخواست پس از پردازش Guardrail

{
  "messages": [
    {
      "role": "user",
      "content": "مقدار کلید api من چیست؟ api_key=[REDACTED]"
    }
  ],
  "guardrails": ["hide-secrets"]
}
```

اگرچه سیستم حفاظ امنیتی ما محافظت قابل توجهی را ارائه می‌دهد، ما همچنان توصیه می‌کنیم بهترین شیوه‌های امنیتی را دنبال کنید و از ارسال اطلاعات حساس در درخواست‌های API خود تا حد امکان خودداری کنید. ما قصد داریم این سیستم را با اقدامات امنیتی پیشرفته‌تر و گزینه‌های سفارشی‌سازی در به‌روزرسانی‌های آینده ارتقا دهیم.

### به‌روزرسانی Gemini 2.5 Flash

گوگل به‌روزرسانی جدیدی برای مدل `gemini-2.5-flash` منتشر کرده است که اکنون از طریق پلتفرم AvalAI در دسترس است. این به‌روزرسانی شامل موارد زیر است:

#### بهبودهای عملکرد

- کاهش 20-30 درصدی استفاده از توکن در ارزیابی‌ها
- بهبود کارایی در عین حفظ خروجی‌های با کیفیت بالا
- عملکرد بهتر در معیارهای کلیدی برای استدلال، چندرسانه‌ای، کد و متن طولانی

#### قابلیت‌های جدید

- **خروجی صوتی بومی**: ایجاد تجربه‌های مکالمه‌ای طبیعی‌تر و بیانگرتر با گفتگوی صوتی بومی
- **تبدیل متن به گفتار**: پشتیبانی از چندین گوینده با توانایی ثبت ظرافت‌های دقیق در بیش از 24 زبان
- **امنیت پیشرفته**: بهبود قابل توجه در محافظت در برابر تهدیدات امنیتی مانند تزریق‌های غیرمستقیم پرامپت
- **استفاده از کامپیوتر**: ادغام با قابلیت‌های استفاده از کامپیوتر پروژه Mariner

#### بهبودهای تجربه توسعه‌دهندگان

- **خلاصه‌های تفکر**: قالب ساختاریافته‌تر و ساده‌تر از فرآیند تفکر مدل برای اشکال‌زدایی آسان‌تر
- **بودجه‌های تفکر**: گسترش یافته به 2.5 Pro، که به توسعه‌دهندگان کنترل بیشتری بر هزینه با متعادل کردن تاخیر و کیفیت می‌دهد

Gemini 2.5 Flash به‌روزرسانی شده اکنون برای پیش‌نمایش در Google AI Studio برای توسعه‌دهندگان، در Vertex AI برای سازمان‌ها، و در برنامه Gemini برای همه در دسترس است. این مدل در اوایل ماه ژوئن برای استفاده در محیط تولید به صورت عمومی در دسترس قرار خواهد گرفت.

### نمونه کدها

```language-selector
python=:from openai import OpenAI

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

# استفاده از مدل به‌روزرسانی شده Gemini 2.5 Flash
completion = client.chat.completions.create(
    model="gemini-2.5-flash-preview-05-20",
    messages=[
        {
            "role": "user",
            "content": "یک شعر کوتاه درباره هوش مصنوعی بنویس.",
        }
    ],
)

print(completion.choices[0].message.content)

javascript=:import { OpenAI } from "openai";

const client = new OpenAI({
  apiKey: process.env.AVALAI_API_KEY,
  baseURL: "https://api.avalai.ir/v1",
});

// استفاده از مدل به‌روزرسانی شده Gemini 2.5 Flash
const completion = await client.chat.completions.create({
  model: "gemini-2.5-flash-preview-05-20",
  messages: [
    {
      role: "user",
      content: "یک شعر کوتاه درباره هوش مصنوعی بنویس.",
    },
  ],
});

console.log(completion.choices[0].message.content);

```
