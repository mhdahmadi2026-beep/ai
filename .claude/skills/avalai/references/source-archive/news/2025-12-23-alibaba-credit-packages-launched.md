# بسته‌های اعتباری Alibaba اکنون در دسترس است

**تاریخ:** ۱۴۰۴-۱۰-۰۲ / (2025-12-23)

## خلاصه

AvalAI بسته‌های اعتباری Alibaba را معرفی می‌کند، مجموعه‌ای جدید از بسته‌های صرفه‌جویی در هزینه برای کاربران مدل‌های هوش مصنوعی Qwen شرکت Alibaba. این بسته‌ها ۲۰ تا ۳۰ درصد تخفیف در ۳۴ مدل Qwen ارائه می‌دهند، با گزینه‌های انعطاف‌پذیر روزانه، هفتگی و ماهیانه متناسب با الگوی استفاده شما.

---

## جزئیات

### معرفی بسته‌های اعتباری Alibaba

بسته‌های اعتباری Alibaba، پیشنهاد ویژه AvalAI برای کاهش هزینه‌های سرویس‌های API هوش مصنوعی است. این بسته‌ها تخفیف‌های قابل توجهی بر روی خانواده جامع مدل‌های Qwen شرکت Alibaba ارائه می‌دهند که شامل تولید متن، کدنویسی، بینایی، تولید تصویر، ترجمه و مدل‌های embedding می‌شود.

### مزایای کلیدی

#### صرفه‌جویی در هزینه
- **بسته‌های روزانه**: ۳۰٪ تخفیف با ۴۲.۹٪ اعتبار اضافی
- **بسته‌های هفتگی**: ۲۰٪ تخفیف با ۲۵٪ اعتبار اضافی
- **بسته‌های ماهیانه**: ۲۰٪ تخفیف با ۲۵٪ اعتبار اضافی

#### انعطاف‌پذیری
- انتخاب بسته‌ها بر اساس شدت استفاده شما
- بسته‌های روزانه برای تست یا استفاده پراکنده
- بسته‌های هفتگی برای توسعه منظم
- بسته‌های ماهیانه برای عملیات‌های سازمانی

#### پوشش جامع مدل‌ها
- دسترسی به ۳۴ مدل Qwen با یک بسته واحد
- پوشش متن، کد، بینایی، تصویر، ترجمه و embedding
- جدیدترین مدل‌ها شامل سری Qwen3

### نحوه عملکرد بسته‌های اعتباری

1. **خرید**: بسته مورد نظر خود را از صفحه [بسته‌های صورتحساب AvalAI](https://chat.avalai.ir/platform/billing/packages?marketplace) انتخاب کنید
2. **فعال‌سازی**: اعتبارات بلافاصله پس از خرید به حساب شما اضافه می‌شوند
3. **استفاده**: اعتبارات بسته به طور خودکار هنگام استفاده از مدل‌های تحت پوشش اعمال می‌شوند
4. **اولویت**: اعتبارات بسته قبل از موجودی کلی شما مصرف می‌شوند
5. **انقضا**: اعتبارات استفاده‌نشده در پایان دوره اعتبار منقضی می‌شوند

### الزامات مهم

> **⚠️ الزام موجودی حساب**
>
> موجودی کلی حساب شما باید مثبت باقی بماند تا بسته‌های اعتباری عمل کنند. حداقل ۰.۲ واحد (UNIT) در موجودی کلی خود حفظ کنید تا از ارائه سرویس بدون وقفه اطمینان حاصل شود.

> **⚠️ استثنای سطح سرویس Flex**
>
> بسته‌های اعتباری هزینه‌های سطح سرویس Flex را پوشش نمی‌دهند. هنگام استفاده از `service_tier: "flex"`، هزینه‌ها از موجودی استاندارد شما کسر می‌شود.

### محدودیت‌های استفاده

- حداکثر ۱ بسته فعال برای هر کاربر از هر نوع بسته
- اعتبارات غیرقابل استرداد و غیرقابل انتقال هستند
- بسته‌ها پس از انقضا قابل تمدید نیستند

```bash
curl -i https://api.avalai.ir/v1/chat/completions \

  }'
```

### پیگیری استفاده از بسته اعتباری با جستجوی تراکنش

شما می‌توانید تایید کنید که بسته اعتباری شما استفاده شده و اطلاعات دقیق هزینه را با استفاده از [API جستجوی تراکنش](fa/api-reference/user.md) پیگیری کنید. از هدر `x-request-id` در پاسخ برای دریافت جزئیات کامل تراکنش استفاده کنید.

#### درخواست جستجوی تراکنش

```bash
curl https://api.avalai.ir/user/v1/transactions/lookup \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -d '{
    "transaction_ids": ["019b4a90-bfed-7cc1-97c1-7abcc10e7e75"]
  }'
```

#### درک پاسخ

پاسخ جستجوی تراکنش اطلاعات دقیقی درباره استفاده از بسته اعتباری ارائه می‌دهد:

- **`cost.source`**: نمایش `"credit_package"` تایید می‌کند که درخواست از بسته شما پرداخت شده است
- **`cost.paid_grant_irt`**: مبلغ کسر شده از بسته اعتباری شما (۱۰.۳۵ تومان در این مثال)
- **`cost.paid_irt`**: مبلغ پرداخت شده از موجودی کلی (۰ هنگام استفاده از بسته اعتباری)
- **`packages`**: جزئیات بسته اعتباری فعال استفاده شده، شامل:
  - `template_id`: کد بسته (مثلا `d-a3550s`)
  - `remaining_irt`: موجودی باقی‌مانده در بسته
  - `scope_details.api`: لیست مدل‌های تحت پوشش
  - `end_date`: زمان انقضای بسته

این به شما امکان می‌دهد دقیقا نحوه مصرف بسته‌های اعتباری خود را پیگیری کنید و موجودی‌های باقی‌مانده را نظارت کنید.

> **نکته**: برای نمایندگان و کاربران سازمانی، [راهنمای پیگیری هزینه](fa/resellers/cost-tracking-guide.md) را برای نظارت و گزارش‌دهی پیشرفته استفاده ببینید.

هنگامی که یک بسته اعتباری Alibaba فعال دارید، درخواست‌های شما به طور خودکار از اعتبارات بسته با نرخ تخفیف‌دار استفاده می‌کنند.
