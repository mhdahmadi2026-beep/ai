# بسته‌های اعتباری AvalAI: صرفه‌جویی تا ۷۰٪ در هزینه‌های هوش مصنوعی

**تاریخ:** 1404-04-16 / (2025-07-07)

## خلاصه

AvalAI با افتخار بسته‌های اعتباری جدید خود را معرفی می‌کند. این بسته‌های پیش‌پرداخت به شما امکان می‌دهند تا در هزینه‌های استفاده از مدل‌های هوش مصنوعی صرفه‌جویی قابل توجهی داشته باشید. با خرید این بسته‌ها، تا ۷۰٪ اعتبار بیشتر از مبلغ پرداختی خود دریافت کنید و از دسترسی به مدل‌های متنوع، متناسب با نیازهای خاص خود، بهره‌مند شوید.

## جزئیات کامل

ما مفتخریم که راه‌اندازی **بسته‌های اعتباری** را به اطلاع شما برسانیم. این قابلیت جدید در سیستم صورتحساب AvalAI طراحی شده است تا به شما کمک کند به طور چشمگیری در هزینه‌های استفاده از مدل‌های هوش مصنوعی صرفه‌جویی کنید و در عین حال به مدل‌های برتر با نرخ‌های تخفیف‌دار دسترسی داشته باشید.

### بسته‌های اعتباری چیست؟

بسته‌های اعتباری، مجموعه‌های پیش‌پرداخت ویژه‌ای هستند که به شما اعتباری بیشتر از مبلغی که پرداخت می‌کنید، ارائه می‌دهند. این بسته‌ها دارای محدودیت‌هایی در مورد مدل‌های قابل استفاده هستند. این رویکرد نوآورانه به ما امکان می‌دهد تخفیف‌های قابل توجهی ارائه دهیم و در عین حال از تخصیص بهینه منابع اطمینان حاصل کنیم.

**مزایای کلیدی:**
- **صرفه‌جویی چشمگیر**: تا ۷۰٪ اعتبار بیشتر نسبت به مبلغ پرداختی خود دریافت کنید.
- **دسترسی به مدل‌های برتر**: با نرخ‌های کاهش‌یافته به مدل‌های پیشرفته‌ای مانند Claude 3.5 Sonnet، GPT-4 و O1 دسترسی پیدا کنید.
- **گزینه‌های منعطف**: بسته‌های متنوعی برای بودجه‌ها و موارد استفاده گوناگون در دسترس هستند.
- **قیمت‌گذاری شفاف**: نسبت‌های ارزش و محدودیت‌های مدل به وضوح مشخص شده‌اند.

- **ارزش**: با پرداخت ۳۰۰,۰۰۰ تومان، ۵۰۰,۰۰۰ تومان اعتبار دریافت کنید (۶۶.۷٪ اعتبار بیشتر).

### نحوه عملکرد بسته‌های اعتباری

1. **خرید**: بسته مورد نظر خود را از [بازار بسته‌های ما](https://chat.avalai.ir/platform/billing/packages?marketplace) انتخاب کنید.
2. **تایید**: فرآیند تایید یک‌بار مصرف (OTP) را برای یک خرید امن تکمیل کنید.
3. **اعمال خودکار**: اعتبارات به طور خودکار بر روی مدل‌های مجاز اعمال می‌شوند.
4. **پیگیری استفاده**: میزان استفاده از بسته خود را به صورت لحظه‌ای از طریق داشبورد اختصاصی‌تان نظارت کنید.

### محدوده‌ها و محدودیت‌های بسته

بسته‌های اعتباری با محدوده‌های خاصی طراحی شده‌اند تا بهترین قیمت‌گذاری را تضمین کنند:

- **تمرکز بر سرویس API**: تمامی بسته‌های فعلی بر استفاده از API متمرکز هستند.

**مهم**: اعتبارات بسته تنها می‌توانند با مدل‌های مجاز در محدوده تعریف‌شده هر بسته استفاده شوند. استفاده از مدل‌های خارج از این محدوده با نرخ‌های استاندارد محاسبه خواهد شد.

### شروع به کار

```language-selector
python=:# بررسی بسته‌های اعتباری شما از طریق API
from openai import OpenAI

client = OpenAI(api_key="AVALAI_API_KEY", base_url="https://api.avalai.ir/v1")

# استفاده از مدل‌های پوشش‌داده‌شده توسط بسته‌های اعتباری شما
response = client.chat.completions.create(
    model="gpt-4o",  # پوشش‌داده‌شده توسط بسته‌های OpenAI
    messages=[{"role": "user", "content": "محاسبات کوانتومی را توضیح دهید"}],
)

print(response.choices[0].message.content)

javascript=:// استفاده از مدل‌های بسته اعتباری با JavaScript
import { OpenAI } from "openai";

const client = new OpenAI({
 apiKey: process.env.AVALAI_API_KEY,
 baseURL: "https://api.avalai.ir/v1"
});

const response = await client.chat.completions.create({
 model: "claude-3-5-sonnet-20241022", # پوشش‌داده‌شده توسط بسته‌های کدنویسی
 messages: [
 { role: "user", content: "یک تابع Python برای مرتب‌سازی لیست بنویسید" }
 ]
});

console.log(response.choices[0].message.content);

bash=:# خرید و استفاده از بسته‌های اعتباری
curl -X POST "https://api.avalai.ir/v1/chat/completions" \
  -H "Authorization: Bearer $AVALAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
 "model": "gpt-4o",
 "messages": [
 {"role": "user", "content": "سلام!"}
 ]
 }'

```

### شرایط مهم

- **غیرقابل استرداد**: بسته‌های اعتباری پس از خرید قابل استرداد نیستند.
- **اعتبار محدود**: هر بسته دارای یک دوره انقضای از پیش تعیین‌شده است.
- **متصل به حساب**: بسته‌ها به حساب کاربری که آن‌ها را خریداری کرده است، متصل هستند.
- **انقضای خودکار**: اعتبارات استفاده‌نشده پس از پایان دوره اعتبار بسته، به طور خودکار حذف می‌شوند.
