# معرفی مدل‌های جدید: اولین مدل‌های متن‌باز OpenAI و بهبود عملکرد API

**تاریخ:** 1404-05-21 / (2025-08-12)

## خلاصه

خرسندیم به اطلاع برسانیم که اولین مدل‌های متن‌باز OpenAI، gpt-oss-120b و gpt-oss-20b، اکنون از طریق Azure AI و AWS Bedrock در دسترس قرار گرفته‌اند. این به‌روزرسانی همچنین شامل بهبودهای چشمگیری در عملکرد API AvalAI است که با کاهش تاخیر و افزایش پایداری، تجربه‌ای ایده‌آل برای کاربردهای تجاری فراهم می‌کند.

---

## جزئیات

### به‌روزرسانی‌های هسته API

ما زیرساخت اصلی API AvalAI را به‌طور قابل توجهی به‌روزرسانی کرده‌ایم تا سرویسی سریع‌تر و پایدارتر ارائه دهیم. این بهبودها مزایای زیر را برای کاربران به همراه دارد:

- **تاخیر کمتر:** کاهش زمان پاسخ‌دهی برای تعاملات سریع‌تر.
- **عملکرد بهتر:** افزایش پایداری و ظرفیت پردازش برای کاربردهای تجاری و در مقیاس بزرگ.
- **پایداری بیشتر:** سرویسی قوی‌تر و قابل اعتمادتر.

این بهبودها نشان‌دهنده تعهد مداوم ما به ارائه بهترین تجربه ممکن در استفاده از API است.

### مدل‌های متن‌باز جدید از OpenAI

برای نخستین بار، OpenAI مدل‌های خود را به صورت متن‌باز منتشر کرده است و ما مفتخریم که این مدل‌ها را از طریق پلتفرم‌های همکار خود در اختیار شما قرار دهیم.

#### Azure AI

- **gpt-oss-120b**: قدرتمندترین مدل وزن‌باز (open-weight) از OpenAI که برای وظایف استدلالی پیچیده طراحی شده و قابلیت اجرا بر روی یک پردازنده گرافیکی (GPU) H100 را دارد. [مستندات](fa/models/gpt-oss-120b.md)

#### AWS Bedrock

- **openai.gpt-oss-120b-1:0**: همان مدل قدرتمند ۱۲۰ میلیارد پارامتری که از طریق AWS Bedrock و با قیمت‌گذاری رقابتی ارائه می‌شود. [مستندات](fa/models/gpt-oss-120b-1-0.md)
- **openai.gpt-oss-20b-1:0**: یک مدل ۲۰ میلیارد پارامتری در اندازه متوسط که برای کاربردهایی با نیاز به تاخیر کم و کارایی بالا ایده‌آل است. [مستندات](fa/models/gpt-oss-20b-1-0.md)

### ویژگی‌های کلیدی مدل‌های جدید

هر دو مدل `gpt-oss-120b` و `gpt-oss-20b` از مجموعه ویژگی‌های قدرتمندی برخوردارند:

- **مجوز آپاچی ۲.۰:** آزادی عمل کامل برای ساخت، سفارشی‌سازی و استقرار تجاری بدون محدودیت‌های حق تکثیر (کپی‌رایت).
- **عمق استدلال قابل تنظیم:** امکان تنظیم عمق استدلال مدل (کم، متوسط، زیاد) متناسب با نیاز شما.
- **زنجیره کامل تفکر (Chain-of-Thought):** شفافیت کامل در فرآیند استدلال مدل برای اشکال‌زدایی آسان‌تر و افزایش اعتماد.
- **قابلیت تنظیم دقیق (Fine-Tuning):** امکان سفارشی‌سازی مدل برای وظایف تخصصی شما.
- **قابلیت‌های عاملی (Agentic):** پشتیبانی داخلی از فراخوانی تابع، مرور وب، اجرای کد پایتون و دریافت خروجی‌های ساختاریافته.

### مثال استفاده

```language-selector
python=:from openai import OpenAI

client = OpenAI(api_key="your-avalai-api-key", base_url="https://api.avalai.ir/v1")

completion = client.chat.completions.create(
    model="gpt-oss-120b",  # or "openai.gpt-oss-120b-1:0"
    messages=[
        {
            "role": "user",
            "content": "اهمیت مجوز آپاچی ۲.۰ را برای مدل‌های متن‌باز شرح دهید.",
        }
    ],
)

print(completion.choices[0].message.content)

javascript=:import { OpenAI } from "openai";

const client = new OpenAI({
 apiKey: process.env.AVALAI_API_KEY,
 baseURL: "https://api.avalai.ir/v1",
});

const completion = await client.chat.completions.create({
 model: "gpt-oss-120b", // or "openai.gpt-oss-120b-1:0"
 messages: [
 {
 role: "user",
 content: "اهمیت مجوز آپاچی ۲.۰ را برای مدل‌های متن‌باز شرح دهید.",
 },
 ],
});

console.log(completion.choices[0].message.content);

```

### قیمت‌گذاری و در دسترس بودن

قیمت‌گذاری این مدل‌ها توسط هر ارائه‌دهنده مشخص می‌شود. برای مثال، قیمت مدل `gpt-oss-120b` در Azure AI با نسخه `openai.gpt-oss-120b-1:0` آن در AWS Bedrock متفاوت است و معمولا نسخه دوم هزینه کمتری دارد. برای اطلاع از جزئیات دقیق قیمت‌گذاری، لطفا به مستندات هر مدل مراجعه فرمایید.
